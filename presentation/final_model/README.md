# final_model — 企業ネットワーク×投資家ABMによる SP500・DGS10 共生成モデル (ZA-FINAL7)

S&P500 の日次リターンと米10年金利 (DGS10) の日次変化を、1966年の実データ水準を初期値として
**60年分まとめて共生成**するエージェントベースモデル (ABM) の最終確定版です。
確定パラメータは `za_final_config.py` の `ZA_FINAL7_PARAMS`。

- 生成物は実データ (`output.csv` / `train_sp500_us10y.csv` 形式) と同じ列構造:
  `Date, sp500_abs (SP500水準), DGS10_abs (金利水準%), sp500 (日次単純リターン), DGS10 (水準の日次差分%pt)`
- 60年1本の生成 ≈ 55〜70秒 (GPU)。CPU でも動作する (`model.py` が参照実装、`model_gpu.py` が PyTorch 実装)

## ファイル構成

## モデルの全体像

1日を1ステップとして、以下を毎日繰り返す:

```
企業の潜在状態が変化 → 投資家が(各自の主観グラフで)観測・信念更新 → 売買判断
→ 注文の需給不均衡が価格を動かす → 外生ショック層(ジャンプ・危機)が加算
→ 指数(SP500)を集計 → 金利(DGS10)を株と相互作用させつつ更新
```

規模: 企業 80社 (8セクター)、投資家 60人、状態次元 20/社。

以下、記号を定義しながら各層を説明する。

### 1. 企業ネットワーク

- 企業間の影響関係を有向重み付きグラフ `W` (80×80) で表す。**Barabási–Albert (BA) モデル**
  (新しいノードが次数に比例した確率で既存ノードに接続する優先的選択のグラフ生成法、
  接続数パラメータ ba_m=3) で生成し、行を正規化する。ハブ企業 (多数の企業から参照される企業)
  が自然にできる。
- 各企業はセクター (8種) にランダム割当。時価総額の初期値はパレート分布×次数で決まり、
  少数の大企業と多数の小企業という現実的な分布を持つ。

### 2. 企業の潜在状態 (ファンダメンタルズ)

各企業 $j$ は 20次元の潜在状態ベクトル $x_j$ を持つ。内訳は
**公開次元 6 (決算等の公開情報) + セクター次元 8 + 私的次元 6 (内部情報)**。
各次元 $k$ は自己回帰しつつグラフ経由で伝播する:

$$
x_{j,k}(t+1) \;=\; \phi_k \, x_{j,k}(t) \;+\; \rho_k \sum_{j'} W_{jj'}\, x_{j',k}(t) \;+\; \eta_k\, \varepsilon_{j,k}(t),
\qquad \varepsilon_{j,k}(t) \sim \mathcal{N}(0,1)
$$

ここで $W_{jj'}$ はグラフ $W$ の (行正規化済みの) 重み。

- 持続性 $\phi_k$ は 0.52〜0.88、伝播強度 $\rho_k$ は 0.06〜0.35 で次元ごとに異なる。
  ゆっくり動く長期的な次元と速く動く短期的な次元が混在する。
- 投資家が観測できるのは公開・セクター次元に観測ノイズを加えたもの。私的次元は直接観測できない。

### 3. 投資家

各投資家 i は以下の個性 (生成時に分布からドロー) を持つ:

- **主観グラフ** `W_i`: 真のグラフ W から、エッジを確率的に間引いたもの。自分の専門セクター
  周辺のエッジは高確率で保持する (専門性)。偽エッジも低確率で混入する。
  つまり投資家は「不完全で人によって違う市場の見取り図」で推論する。
- **投資ユニバース**: 各投資家は自分の専門セクターとグラフ近傍を中心とした最大36銘柄しか
  売買しない (`universe_max_size=36`)。1銘柄あたりの実効参加者数を規模によらず保つ仕組みで、
  企業数を増やしてもスタイライズドファクトが保たれる (スケール不変性)。
  ハブ企業への参加は48人までに制限 (`universe_hub_cap=48`)。
- **信念状態**: 投資家 i は全企業の潜在状態の推定値 (信念) を保持し、毎日
  「自分の主観グラフでの予測 → 観測との混合 (更新率 α は公開/セクター/私的次元で別)」で更新する。
  私的次元は直接観測できないため、主観グラフ経由の擬似観測で補う。

投資家 $i$ の企業 $j$ に対する**取引スコア** $s_{ij}$。
$\hat{x}^{(i)}_j$ を投資家 $i$ の企業 $j$ に対する現在の信念 (推定値の集約)、
$\hat{x}^{(i)+}_j$ を主観グラフで1期先に伝播させた来期予測、
$u_i$ を推定の不確実性 (観測・過程ノイズ分散から計算)、$y$ を金利水準として:

$$
s_{ij} \;=\; v_i\, \hat{x}^{(i)+}_j
\;+\; \tau_i \left( \hat{x}^{(i)+}_j - \hat{x}^{(i)}_j \right)
\;-\; a_i\, u_i
\;-\; g_i\, y
\;+\; (\text{レジーム項: } \kappa \times \text{金利変化。} \kappa \text{ は §7})
$$

ここで $v_i$ (バリュー重視度)、$\tau_i$ (トレンド追随度)、$a_i$ (不確実性回避度)、
$g_i$ (金利感応度) は投資家ごとの個性。第2項は信念の変化方向への追随を表す。

スコアから買い/売り確率を作る。$T_i$ はスコア感度 (温度)、$\lambda_i \ge 1$ は損失回避度、
$\pi_i(t)$ は参加率 (下記) として:

$$
z^{\text{buy}}_{ij} = e^{T_i s_{ij}}\, \pi_i, \qquad
z^{\text{sell}}_{ij} = e^{-\lambda_i T_i s_{ij}}\, \pi_i
$$

$$
P(\text{買い}) = \frac{z^{\text{buy}}_{ij}}{z^{\text{buy}}_{ij} + z^{\text{sell}}_{ij} + 1}, \qquad
P(\text{売り}) = \frac{z^{\text{sell}}_{ij}}{z^{\text{buy}}_{ij} + z^{\text{sell}}_{ij} + 1}
$$

- **参加率** $\pi_i(t)$ は市場ボラティリティに応じて増減する (ボラ選好 vol_sensitivity が
  正の投資家は荒れ相場で活発化、負の投資家は退避)。日次の iid ノイズも乗る。
- **注文サイズ**: 買いは現金×比率、売りは保有時価×比率。比率はリスク許容度×確信度で決まり
  0.02%〜8% にクリップ。現金を超える買いは比例縮小 (空売り・借入なし)。
- **ストレス記憶**: 大きな下落は投資家ごとの減衰率 (半減期 数日〜138日) で記憶され、
  記憶が閾値を超えるとリスク回避的な投資家の売りが増える (パニックの持続)。

### 4. キャパシティ制約と状態依存ファイアセール (富の凝縮対策)

60年の複利で一部投資家の富が極端に集中すると (放置すると実効投資家数が1人まで崩壊する)、
その1人の売買が市場を支配して「直近ほど平穏期ボラが上がる」「暴騰暴落が頻発する」という
非現実的な経年変化 (ラチェット) が生じる。実市場の大規模ファンドと同じく:

投資家 $i$ の富を $w_i$、投資家数を $N$、相対富シェアを
$r_i = \max\!\left(1,\; \dfrac{w_i N}{\sum_{i'} w_{i'}}\right)$ とする ($r_i=1$ が平均、大口ほど大)。

- **キャパシティ制約 (買い側)**: 買い注文額を $r_i^{-\gamma}$ 倍に縮小する
  ($\gamma = 0.5$, `whale_size_power`)。大口ほど富の小さい割合しか日々動かせない。
- **状態依存ファイアセール (売り側)**: 売り注文額は $r_i^{-\gamma_{\text{sell}}}$ 倍。
  平時は $\gamma_{\text{sell}} = \gamma$ だが、下方ストレス比
  $\theta = \dfrac{\text{down\_var\_ewma}}{\text{realized\_var\_ewma}/2}$
  (下落由来の分散が全分散に占める比率。両者の定義は §5) が高い局面では

$$
\gamma_{\text{sell}} = \gamma \left( 1 - \mathrm{clip}\!\left( \frac{\theta - 0.8}{0.6},\, 0,\, 1 \right) \right)
$$

  と制約を解除する (`whale_fire_thresh=0.8`, `whale_fire_width=0.6`, `whale_fire_sale_relief=1.0`)。
  「平時は執行制約・危機は投げ売り」という実市場の非対称が、暴落の増幅 (レバレッジ効果) を保つ。

これにより60年を通じて平穏期ボラの床が定常になる。
なお投資家の参入・退出 (資本回転) 機構もコードに実装されているが、最終版では無効
(`investor_turnover_mean_years=0`)。

### 5. 価格形成

企業 $j$ への当日の買い注文総額を $B_j$、売り注文総額を $S_j$ として、需給不均衡と日次リターンは:

$$
I_j \;=\; \frac{B_j - S_j}{B_j + S_j} \;\in\; [-1,\, 1]
$$

$$
r_j \;=\; \underbrace{c \cdot F \cdot I_j}_{\text{需給インパクト}}
\;+\; \underbrace{\epsilon_c}_{\text{共通ノイズ}}
\;+\; \underbrace{\epsilon_j}_{\text{個別ノイズ (t分布)}}
\;+\; f_j \;+\; m \;+\; q
$$

- $c = 0.019$ (`price_impact`) が基本の価格インパクト、$F$ は下記の非対称インパクト係数。
- $f_j$ は企業ファンダメンタルへの回帰項、$m$ は指数水準アンカー項、$q$ は金利チャネル項 (いずれも下記)。
- $F$ は**非対称インパクト係数**。指数リターン $r_{\mathrm{SP}}$ の下落成分から作る
  下落分散 (指数加重移動平均、EWMA):

$$
\text{down\_var\_ewma}(t) = 0.75\,\text{down\_var\_ewma}(t-1)
+ 0.25\left( \max(-r_{\mathrm{SP}} - \delta,\, 0)^2 + 0.6\,\max(-r_{\mathrm{SP}} - \delta,\, 0)\,\sigma_0 \right)
$$

  ($\delta$ は微小下落を無視するデッドバンド、$\sigma_0$=0.0045 は基準ボラ、
  線形項の係数 0.6 が `down_linear_coef`)。これが実現分散
  $\text{realized\_var\_ewma}(t) = 0.95\,\text{realized\_var\_ewma}(t-1) + 0.05\, r_{\mathrm{SP}}^2$
  に対して大きいとき $F > 1$ となり、インパクトが増幅される
  (下げ相場で流動性が薄くなる効果 → レバレッジ効果・ボラクラスタの源)。
- $f_j$: 各企業のファンダメンタル価値 (潜在状態に連動して成長) への弱い回帰。
- $m$: 指数水準の長期アンカー項。アンカー水準 $A(t)$ は
  $A(t) = A(t-1)\, e^{\mu + d(t)}$ ($\mu = 0.00030$、年率約 7.5%。実データの長期成長に校正)
  で成長し、ドリフト状態 $d(t)$ はパスごとの AR(1) 確率過程
  ($d(t) = 0.999\, d(t-1) + \xi_t$、$\xi_t \sim \mathcal{N}(0, \sigma_d^2)$、$\sigma_d = 10^{-6}$、
  専用乱数系列) で終値の多様性を作る。
  $m$ は指数水準と $A(t)$ の乖離を縮める方向の弱い項。
- $q$: 金利変化の価格直接チャネル ($\kappa \times$ 金利変化に比例。$\kappa$ は §7)。

指数リターンは時価総額加重: $r_{\mathrm{SP}}(t) = \sum_j \omega_j(t)\, r_j(t)$
($\omega_j$ は企業 $j$ の時価総額ウェイト)。

### 6. 外生ショック層 (ジャンプ・危機)

共通ノイズ $\epsilon_c$ (全銘柄に同時に加わる成分) は次の合成:

- 日常の共通ノイズ: $\mathcal{N}(0,\, \sigma_c^2)$、$\sigma_c = 0.0064$。
  ただし $\sigma_c$ は下記の余震係数で日々増幅される
- **中規模ジャンプ**: 確率 1.2%/日 で標準偏差 1.4% のジャンプを加算
- **メガクラッシュ**: 確率 0.0067%/日 (60年で約1回) の単日 $-18\%$ 級 (1987年型)
- **危機エピソード**: 確率 0.04%/日 で発火。強度 $D(t)$ が 1 から始まり、6日間持続
  (プラトー) の後 $D(t+1) = 0.78\, D(t)$ で幾何減衰。持続中は毎日

$$
\epsilon_{\text{crisis}}(t) \;=\; 0.044\, D(t)\, z_t \;-\; 0.007\, D(t),
\qquad z_t \sim t\text{分布}
$$

  を加算 (連続する大きな日次ショックがボラクラスタと深い週次下落を作る。
  負ドリフト $-0.7\%/$日 とプラトー6日は、実データの最悪5日/21日累積下落
  $-29\%/-36\%$ に校正)
- **余震**: 直近のジャンプ量の絶対値 $J(t)$ を2つの時定数で記憶し、共通ノイズの
  標準偏差を増幅する:

$$
a_1(t) = 0.80\, a_1(t-1) + J(t), \quad a_2(t) = 0.985\, a_2(t-1) + J(t)
$$

$$
\sigma_c(t) = \sigma_c \left( 1 + 30\, a_1(t) + 10\, a_2(t) \right)
$$

  遅い余震 $a_2$ (減衰 0.985/日 = 半減期46日) が自己相関関数 (ACF) の lag5〜60 の裾
  (ボラの長い記憶) を作る。

### 7. 金利 (DGS10) の生成と株との相互作用

金利水準 $y(t)$ (%) の日次変化 $\Delta y$:

$$
\Delta y \;=\; \underbrace{d_r(t)}_{\text{AR(1)確率ドリフト}}
\;+\; \underbrace{0.012\,\bigl(6.0 - y\bigr)}_{\text{平均回帰 (中心 6.0)}}
\;+\; \underbrace{\sigma_r(t)\, z_t}_{\text{水準依存ボラ} \times t\text{分布}}
\;+\; \underbrace{G(t)}_{\text{株→金利チャネル}}
$$

$$
\sigma_r(t) \;=\; 0.030 \left( \frac{y}{5} \right)^{0.85} \sqrt{h(t)}
$$

- 水準依存ボラ $(y/5)^{0.85}$: 高金利期ほど金利変化が大きい (1980年代型)。
  $h(t)$ は金利自身のショック二乗の指数加重移動平均 (2時定数のボラクラスタ項)。
- **レジーム係数**:

$$
\kappa \;=\; \tanh\!\left( \frac{5.5 - y}{1.5} \right)
$$

  金利水準で株と金利の相関の符号が切り替わる。低金利期 ($y < 5.5$) は $\kappa > 0$ で
  リスクオン相関 (株高→金利高)、高金利期は $\kappa < 0$ で割引率相関。
  実データの「時代によって株金利相関の符号が違う」構造の再現。
- 株→金利チャネル $G(t)$ の内訳 ($r_{\mathrm{SP}}$ は当日の指数リターン、$D(t)$ は危機強度):

$$
G(t) \;=\; 2.5\, \kappa\, r_{\mathrm{SP}}
\;+\; 3.5\, \min(D(t), 1)\, r_{\mathrm{SP}}
\;+\; 1.2 \cdot \frac{1}{20} \sum_{k=1}^{20} r_{\mathrm{SP}}(t-k)
$$

  - 第1項: レジーム相関の本体
  - 第2項: **危機エピソード限定 flight** ($\kappa$ 非依存)。「本物の暴落では高金利時代でも
    質への逃避で金利が急落する」(1987年型) の再現。株の極端リターン分位で金利との相関が
    持ち上がる実データの構造を作る
  - 第3項: **リードラグ** — 金利が株の20日トレンドを遅れて追う (景気期待チャネル)
- 逆方向 (金利→株) は、投資家スコアの金利感応項 ($-g_i\, y$)・$\kappa$ 付きレジーム項、
  および価格式の金利チャネル項 $q$ を通じて働く。

### 8. 乱数と再現性

- 全体は `seed` 1つで再現可能。確率ドリフト (§5) と資本回転は**専用の乱数系列**
  (seed+990001 / seed+770001) を使う。共有系列から引くと、パラメータ変更時に
  以降の全乱数がずれて共通乱数法による機構比較が壊れるため。

### 60年パス (histinit 形式)

```bash
python generate_histinit.py                    # seed 1-10、results/histinit/ に出力
python generate_histinit.py --seeds 1 2 3
```

出力: `60y_paths/generated_paths_seedNN.csv` (60年パス)、
`5y_paths/generated_paths_seedNN-C.csv` (約5年×12チャンク)、
`60y_summary.csv`・`split_metadata.csv`・`config_seedNN.json`。

### 5年×1000パスの wide 形式 CSV

```bash
python generate_5y_1000paths.py                # results/synthetic_returns_final7_1000paths_wide.csv
```

60年パス30本を生成 (プールは `results/60y_pool/` にキャッシュされ再実行時はスキップ) し、
ランダムな1260日窓を1000個切り出して1つの CSV にまとめる。列は
`step, date, sp500_path_0, dgs10_path_0, …, sp500_path_999, dgs10_path_999`
(sp500_path_i は日次単純リターン、dgs10_path_i は金利水準の日次差分)。
各窓の由来 (元パスの seed・期間) は `*_meta.csv` に記録される。
