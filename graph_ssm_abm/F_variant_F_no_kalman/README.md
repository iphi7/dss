# F_variant_F_no_kalman

## 概要

アブレーション: **カルマンフィルタの有無**がスタイライズドファクトに与える影響を検証する。

## 検証の動機

base モデルでは投資家が毎期カルマン更新で状態推定を行っているが、観測ノイズが小さく gain $K \approx 0.6 \sim 0.8$ になるため、更新後の推定値がほぼ観測値に収束してしまう。この場合「カルマンを使った版」と「観測をそのまま使う版」に差がないはずであり、カルマンフィルタが実質的に機能していないことを数値で確認する。

## 実装

`Config.use_kalman: bool` フラグを追加。

```python
if config.use_kalman:
    pred = a_i @ estimates[i]
    gain = pred_var / (pred_var + p["obs_var"])
    updated = pred + gain * (y - pred)
else:
    updated = y.copy()   # 観測をそのまま採用、グラフ・予測モデル不使用
```

## 結果

| 指標 | real_tail | base (kalman) | no_kalman |
|---|---:|---:|---:|
| std | 0.01065 | 0.01353 | 0.01358 |
| kurtosis | 10.10 | 6.43 | 6.42 |
| \|r\| ACF lag-1 | 0.163 | 0.060 | 0.059 |
| \|r\| ACF lag-5 | 0.198 | 0.020 | 0.017 |
| leverage | -0.043 | +0.000 | +0.000 |

→ **全指標でほぼ完全に一致。カルマンフィルタはスタイライズドファクトに影響しない。**

## 解釈

カルマンありでも更新後の推定値はほぼ観測値 $y$ になるため、カルマンなしと同等の取引行動になる。根本的な問題は2つ：

1. **取引スコアが将来予測ではなく現在の推定値ベース** — グラフ $W_i$ や `belief_phi/rho` は `pred = A_i @ estimates` に現れるが、この `pred` はカルマンの中間変数として消費されスコアには使われない
2. **価格形成に真の $x$ が直接介入している** — `latent_price_beta * x` が推定精度の差を打ち消す

## 今後の方向性

- 取引スコアを「来期予測」ベースに変更: `score = f(pred_next)` where `pred_next = A_i @ y`
- 公開/非公開成分の分離により、観測から回復できない不確実性を構造的に導入
- 価格形成を注文不均衡ベースに純化（真の $x$ の直接介入を除く）
