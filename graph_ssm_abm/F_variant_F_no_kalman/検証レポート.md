# F系検証レポート: カルマンフィルタの有無のアブレーション

## 目的

投資家の状態推定にカルマンフィルタを使うことが、スタイライズドファクトに影響を与えているかを検証する。

カルマンなしの場合、投資家は毎タイムステップの観測値 $y_j$ をそのまま推定値として採用する（グラフ $W_i$ も予測モデルも使わない）。

## 実装

| 条件 | 投資家の推定値 | グラフ・動的モデルの使用 |
|---|---|---|
| base (kalman) | $\hat{x}^{(i)} = \hat{x}^{(i)-} + K(y - \hat{x}^{(i)-})$ | 使用 |
| no_kalman | $\hat{x}^{(i)} = y$（観測値そのまま） | 不使用 |

## 結果

| 指標 | real\_tail | base (kalman) | no\_kalman |
|---|---:|---:|---:|
| std | 0.01065 | 0.01353 | 0.01358 |
| skew | +0.158 | -0.102 | -0.105 |
| kurtosis | 10.10 | 6.43 | 6.42 |
| \|r\| ACF lag-1 | 0.163 | 0.060 | 0.059 |
| \|r\| ACF lag-5 | 0.198 | 0.020 | 0.017 |
| leverage | -0.043 | +0.000 | +0.000 |
| 株債相関 | -0.059 | -0.011 | -0.011 |

## 解釈

**カルマンありとなしで全指標がほぼ完全に一致した。**

カルマンフィルタは現在のモデルにおいて価格形成に対して意味のある寄与をしていない。

### 理由

**カルマン更新が観測値への収束として機能している**

現在のモデルでは観測ノイズ $R_i$ が小さいため（`obs_var` は $\log(0.055^2)$ を中心に分布）、カルマンゲイン

$$K^{(i)}_j = \frac{P^{(i)-}_j}{P^{(i)-}_j + R_i}$$

が $K \approx 0.6 \sim 0.8$ 程度になる。つまりカルマン更新後の推定値

$$\hat{x}^{(i)}_j = \hat{x}^{(i)-}_j + K (y_j - \hat{x}^{(i)-}_j)$$

はほぼ $y_j$ に近い値になる。「カルマンあり → ≈ $y_j$」と「カルマンなし → $= y_j$」の差が小さく、両者の取引行動がほぼ同一になる。

**価格形成に真の $x$ が直接介入している**

```python
firm_return = price_impact * imbalance + latent_price_beta * x + ...
```

取引行動（imbalance）の違いが仮にあっても、`latent_price_beta * x` という真の状態の直接介入がリターンを支配しているため、推定精度の差が価格に反映されにくい。

## 結論

カルマンフィルタは現状のモデルで機能していない。根本的な理由は2つある：

1. **観測を強く信頼しているため**、カルマン更新が「観測値を採用する」という素朴な戦略と事実上同じ結果になっている
2. **価格形成に真の $x$ が直接介入している**ため、推定の精度差が価格に伝わらない

カルマンフィルタを有効に機能させるには、[問題点.md](../問題点.md) に記載した通り：
- 観測モデルを $H \neq I$ にして、観測から直接は回復できない成分を作る
- 価格形成を注文不均衡ベースに純化し、真の $x$ の直接介入を除く

の両方が必要である。
