# M系検証レポート: c_t 外生化 + リスク選好によるボラクラ

## 目的

1. **c_t の外生化**: GARCH omega を market_stress から切り離し、c_t を「外生ショック」として機能させる
2. **vol_sensitivity**: 投資家がボラ水準に応じてポジションサイズを変える (リスク選好型 → 高ボラ時に積極売買)
3. **vol_activity チャネル**: 取引量 EWMA を通じて投資家行動が GARCH omega に影響する

## 実装

### c_t の外生化
`garch_stress_scale=0.0` → base_var は固定の σ²_mkt のみ。
GARCH は安定条件 α × (5/3) + β < 1 を満たすよう α=0.05, β=0.88 (α+β=0.93) に変更。

### vol_sensitivity パラメータ
```python
vol_sensitivity ~ Normal(+0.40, 0.60)  # 正寄り = 平均的にリスク選好
vol_ratio = prev_market_vol_t / config.market_vol
vol_factor = clip(1 + vol_sensitivity × (vol_ratio - 1), 0.05, 4.0)
size_frac = risk_tolerance × vol_factor × (0.25 + conviction)
```

### vol_activity チャネル (fast/slow EWMA)
```python
# fast EWMA (λ=0.94, 半減期~11日): 直近の取引量変動
# slow EWMA (λ=0.99, 半減期~69日): 長期 baseline
volume_ratio = fast_ewma / slow_ewma   # mean-revert + spike後 ~11日持続
base_var = σ²_mkt × (1 + vol_activity_scale × max(0, volume_ratio - 1))
```

## 主な知見

### 1. c_t の外生化 (R0 → R1) が std と leverage を大幅改善

| 指標 | R0 (stress依存) | R1 (外生) | 実データ |
|---|---:|---:|---:|
| std | 0.01272 | **0.01030** | 0.01065 |
| leverage | −0.010 | **−0.020** | −0.043 |

- GARCH 安定条件 (α × 5/3 + β < 1) を満たすことで市場ボラが適正水準に収束する
- market_stress への依存が切れ、GARCH 固有の持続性 (β=0.88) のみが残る
- leverage_vol_beta 由来のレバレッジ効果がより鮮明に現れる

### 2. vol_sensitivity のみでは効果なし (R1 vs R2/R3)

vol_factor の変動域 (0.96–1.40) が小さく、price_impact の SNR (≈0.067) が低いため、
ポジションサイズ変更が imbalance チャネル経由で価格に届かない。

### 3. vol_activity チャネル (R1 → R7) が kurtosis を劇的に改善

**kurtosis: 7.13 → 9.19** (実データ 10.10 に近づく)

機構:
1. 偶発的な大きな c_t → 高 market_vol_t → risk-seeking 投資家の vol_factor 上昇 → 大量売買
2. total_trade 増大 → fast_ewma > slow_ewma → volume_ratio > 1 → base_var 増大
3. 次期 c_t の分散増大 → さらに大きな価格変動 → 一時的な「ボラ爆発」
4. EWMA の半減期 ~11日後に収束 → ファットテールだが長期 drift なし

### 4. vol_sensitivity + vol_activity の相乗効果は小さい (R7 vs R8)

kurtosis: 9.19 → 9.27 (わずかな改善)。vol_activity が主要な機構であり、
vol_sensitivity (position size scaling) の追加効果は限定的。

### 5. vol_activity_scale の最適値は 2.0

scale=4 は base_var が GARCH cap (0.012²) に頻繁に当たり、kurtosis が低下する。
scale=2 → volume_ratio が 1.5 のとき base_var が 2.0× — これが最適。

### 6. fast EWMA のλ (半減期) は 0.94 が最適

λ=0.97 (半減期 23日) は kurtosis 8.45 と逆に悪化。スパイクの「鋭さ」が重要。
