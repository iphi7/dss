# Variant C2: 指数減衰メモリ + 企業ネットワーク伝播

## 追加した機構

Cの指数減衰メモリに加え、企業不確実性メモリを企業ネットワーク上で伝播させた。

$$
u_{j,t}
=
\lambda_u u_{j,t-1}
+
(1-\lambda_u) s_{j,t}
+
\rho_u \sum_k W_{jk}u_{k,t-1}
$$

ここで $s_{j,t}$ は $|x_{j,t}|, |\Delta x_{j,t}|, |\eta_{j,t}|$ から作るショック信号である。

さらに、企業メモリを次期の潜在ショック分散にも反映した。

$$
\eta_{j,t}
\sim
\mathcal{N}
\left(
0,
\sigma_\eta^2
\left(
1+c_\eta u_{j,t-1}
\right)^2
\right)
$$

これにより、

```text
企業ショック
→ 企業メモリ上昇
→ 次期以降も潜在ショック分散・観測ノイズ・価格インパクトが高い
→ |r| ACF が上がる
```

という経路を作った。

## 所感

C2_strongでは、lag 1 と lag 5 の絶対リターン自己相関が明確に上がった。

$$
\mathrm{ACF}_{|r|}(1): 0.062 \rightarrow 0.076
$$

$$
\mathrm{ACF}_{|r|}(5): 0.037 \rightarrow 0.094
$$

一方で、標準偏差が大きくなりすぎ、尖度は低下した。これはメモリが広く効きすぎて、高ボラ状態が厚尾というより「常時やや荒い状態」になっているためと考えられる。

C2_scaledではスケールを抑えたが、クラスタリングも弱まった。したがって、現状では

- 分かりやすいボラティリティクラスタリングを見るなら C2_strong
- スケールを保つなら C2_scaled

というトレードオフになっている。

次の改善候補は、企業メモリを全企業に一様に効かせるのではなく、

1. セクター単位で伝播を制限する
2. 注文量ではなく流動性・価格インパクト中心に効かせる
3. 正負メモリを分け、悪化メモリだけ長く残す
4. 共通ショックを弱め、企業ネットワーク由来のクラスタリングを主役にする

である。
