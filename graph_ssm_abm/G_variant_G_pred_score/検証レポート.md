# G系検証レポート: 来期予測ベーススコアのアブレーション

## 目的

取引スコアを「現在の観測値」ベースから「来期予測値」ベースに変更し、グラフ $W_i$ の個性が価格形成に反映されるかを検証する。

## 実装

| 条件 | スコアの基準 | グラフの役割 |
|---|---|---|
| base_no_graph | $y$（現在観測値）をそのまま使用 | なし |
| pred_score | $\hat{x}^{(i)}_{t+1} = \phi_i y + \rho_i W_i y$ | スコアに直接入る |

カルマンフィルタはどちらも廃止。スコア計算：

```python
# pred_score
pred_next = belief_phi * y + belief_rho * (W_i @ y)
delta     = pred_next - y   # 予測される変化量
score     = value_weight * pred_next + trend_weight * delta - ...

# base_no_graph
score     = value_weight * y + trend_weight * (y - y_prev) - ...
```

## 結果

| 指標 | real\_tail | base\_no\_graph | pred\_score |
|---|---:|---:|---:|
| std | 0.01065 | 0.01372 | 0.01371 |
| skew | +0.158 | -0.076 | -0.079 |
| kurtosis | 10.10 | 6.13 | 6.15 |
| \|r\| ACF lag-1 | 0.163 | 0.063 | 0.063 |
| \|r\| ACF lag-5 | 0.198 | **0.069** | **0.069** |
| leverage | -0.043 | +0.011 | +0.011 |
| 株債相関 | -0.059 | +0.053 | +0.053 |

## 解釈

### グラフの効果はやはり出なかった

pred_score と base_no_graph はほぼ完全に一致した。

理由：グラフ項の寄与は $\rho_i \approx 0.12$ に比例するのに対し、自己回帰項は $\phi_i \approx 0.80$ であるため、

$$\hat{x}^{(i)}_{t+1} = \underbrace{0.80 \cdot y}_{\text{支配項}} + \underbrace{0.12 \cdot W_i y}_{\text{微小補正}}$$

グラフの有無による $\hat{x}^{(i)}_{t+1}$ の差は小さく、投資家間の取引行動の差も微小にとどまる。

### ACF lag-5 が改善した

ただし base_no_graph / pred_score 共通で、前世代の base (カルマンあり) と比べて **|r| ACF lag-5 が 0.020 → 0.069 に改善**した。

前世代の base では `delta = updated - estimates_prev`（カルマン更新済み推定値の差分）をトレンドとして使っていたが、本バリアントでは `delta = y - y_prev`（観測値の差分）や `pred_next - y`（予測変化量）を使う。後者の方が観測ノイズを含む生の変化を直接スコアに入れるため、投資家の反応が時系列的に広がり、|r| の持続性が出たと考えられる。

### 株債相関の符号反転

株債相関が -0.011 → +0.053 に反転してしまった。実データ (-0.059) とは逆方向。金利感応度パラメータ `rate_sensitivity` の調整が必要と思われる。

## 残された問題

グラフ $W_i$ の個性をスコアに入れても差が出ない根本原因は、**$y \approx x$ であること**（観測から真の状態がほぼ回収できる）。グラフを有意義にするには：

1. **公開/非公開成分の分離** — $y_j = x_j^{\text{pub}} + \varepsilon_j$ にして $x_j^{\text{priv}}$ を直接観測不能にする
2. そのうえで `pred_next` を介して $x_j^{\text{priv}}$ をグラフ経由で推定させる

詳細は [../問題点.md](../問題点.md) を参照。
