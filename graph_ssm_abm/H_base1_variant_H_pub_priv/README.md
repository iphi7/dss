# B_base1_H_variant_H_pub_priv（第2基準モデル）

E〜G 系のアブレーションで判明した問題を反映した第2の基準モデル。  
詳細なアーキテクチャ説明は [アーキテクチャ.md](アーキテクチャ.md) を参照。

## 概要

設計変更: **公開/非公開成分の分離** + **カルマン廃止** + **来期予測ベーススコア** + **価格形成の純化**

- 潜在状態を `s`（IR情報等で観測可能）と `h`（内部情報・観測不可）に分離
- 投資家は `W_i @ y` 経由でのみ `h` を推定できる
- カルマンフィルタ廃止（variant_F で不要を確認済み）
- スコアを来期予測ベースに変更（variant_G で実装済み）
- 価格形成から真の `x` の直接介入を除去（問題点.md 問題4を対処）

## 真の動態

```
s_{t+1} = phi_s * s_t + rho_s * W @ s_t + eta_s    (phi_s=0.82, rho_s=0.13)
h_{t+1} = phi_h * h_t + rho_h * W @ h_t + eta_h    (phi_h=0.90, rho_h=0.35)
y_j = s_j + noise    # h は観測不能
```

## 結果

no_graph と with_graph はほぼ一致 → グラフ多様性は集計平均で消える。

株債相関が実データに近い符号 (-0.072) になった副次的改善あり。

→ 詳細は [検証レポート.md](検証レポート.md)

## 判明した根本問題

60人の異なる $W_i$ による注文が合計されると $\sum_i W_i \approx N \cdot W$ に収束する（大数の法則）。指数・時価総額加重でさらに平均化される。グラフ多様性を有効にするには **平均化されない構造**（資産不平等・部分的投資ユニバース等）が必要。
