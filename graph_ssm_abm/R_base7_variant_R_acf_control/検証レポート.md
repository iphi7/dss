# R_base7_variant_R_acf_control 検証レポート

## 目的

前回の `Q_base6_variant_Q_longrun_stable` では、60年生成の安定性は改善したものの、全期間で見ると自己相関が強すぎました。
特に問題だったのは以下です。

- raw return の lag 1 ACF が `0.15〜0.18` 程度出る。
- `|r_t|` の ACF が実データの2〜3倍程度出る。
- `r_t^2` の ACF も過剰。

今回はこのうち、特に「2. volatility clustering 過剰」と「3. raw return ACF 過剰」を考慮して、モデルを再調整しました。

## 実データとQ系の問題

実データ全期間ではおおよそ

| 指標 | 実データ |
|---|---:|
| `r_acf1` | -0.015 |
| `abs_acf5` | 0.289 |
| `sq_acf5` | 0.228 |
| `std` | 0.0105 |
| leverage | -0.046 |

一方、Q17/Q20では

- `r_acf1 ≈ 0.15〜0.18`
- `abs_acf5 ≈ 0.54〜0.76`
- `sq_acf5 ≈ 0.56〜0.76`

となり、明らかに過剰でした。

## Round1: momentum削除 + 状態依存弱体化

P/Qで固定だった momentum 項を削除しました。

$$
s_{i,j,t} \leftarrow s_{i,j,t} + \beta_m r_{t-1},
$$

について、Qでは実質 $\beta_m=0.25$ でしたが、Rでは主に $\beta_m=0$ としました。

結果として raw return ACF は大きく改善しました。
特に `R03_more_tail seed2` は以下です。

| 指標 | R03 seed2 |
|---|---:|
| std | 0.0126 |
| kurt | 5.89 |
| r_acf1 | 0.008 |
| abs_acf5 | 0.328 |
| sq_acf5 | 0.238 |
| leverage | -0.013 |
| ann return | 0.066 |

`r_acf1`, `abs_acf5`, `sq_acf5` はかなり実データに近づきました。
ただし leverage が弱く、seed1ではボラクラがほぼ消えるというseed依存が残りました。

## Round2: 短い記憶でボラクラ/leverageを戻す

activity impact と fear を少し戻しました。
しかし、rolling windowではACFが低い一方、seedによって全期間ACFが大きくなる現象が残りました。
これは短期ボラクラというより、60年中の長期レジーム差が全期間ACFとして見えている可能性があります。

## Round3: portfolio rebalancing

投資家の保有・現金構成が60年固定化することを避けるため、弱い rebalancing を入れました。

これは全期間ACFの長期レジームを消す方向には効きましたが、効きすぎました。
`abs_acf5` が `0.02` 程度まで落ち、標準偏差も `0.005〜0.006` 程度になりました。
したがって、日次rebalancingは強すぎると判断します。

## Round4: tiny rebalancing

rebalancing rate を `0.001` まで落とし、activity とノイズを戻しました。
`R12_tiny_rebal_active seed2` は中間的な結果になりました。

| 指標 | R12 seed2 |
|---|---:|
| std | 0.0098 |
| kurt | 8.61 |
| r_acf1 | 0.036 |
| abs_acf5 | 0.196 |
| sq_acf5 | 0.104 |
| leverage | -0.014 |
| ann return | 0.061 |

ただし seed1ではまだボラクラが弱く、全体としては不十分です。

## 現時点の評価

今回のサイクルで改善した点:

- Q17/Q20で非常に悪かった raw return ACF は大きく改善。
- `abs_acf5` / `sq_acf5` の過剰もかなり抑えられた。
- 60年の指数崩壊は起きていない。

まだ悪い点:

- leverage が弱い。
- seed依存が強い。
- ボラクラを抑えると消えすぎ、戻すとseedによって全期間ACFが膨らむ。
- skew は依然として実データの負の歪みに届かない。

## 暫定候補

### ACF-control候補: R03_more_tail

`R03_more_tail` は、全期間ACFの過剰を抑えるという今回の目的に対して最も良い候補です。
特に seed2 はかなり良いです。

ただし seed1 ではボラクラが弱いため、最終候補としてはまだ不安があります。

### stationarity候補: R12_tiny_rebal_active

`R12` は rebalancing によって長期レジーム化を抑える方向ですが、ボラクラ/leverageが弱いです。
こちらは「長期安定側の下限」として参考になります。

## 次の改善案

次は `R03` と `Q17` の中間ではなく、より構造的には次が良いです。

1. momentum は引き続き 0 にする。
2. fear / price impact の memory をさらに短くする。
3. portfolio rebalancing は毎日ではなく、低頻度・確率的な投資家入替として入れる。
4. leverage は market-wide fear ではなく、下落後に一部の投資家だけが売り急ぐ heterogeneity として入れる。
5. 評価関数には必ず全期間 `r_acf1`, `abs_acf5`, `sq_acf5` を入れる。

今回の結論として、Q系の過剰ACFの主因はかなり特定できました。
最大の犯人は固定 momentum 項と、長く効きすぎる activity/fear 系の状態依存です。
