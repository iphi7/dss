# ZA_goal09_variant_ZA_minimal_final

**目標**: Z117（Z_goal08 の最終候補）をベースにアブレーションで簡素化し、
そこから残った課題を反復改善して、SP500 と DGS10 の60年日次パスを1966年初期値から
共生成する最終モデルを作る。

## 出発点

- ベースモデル: Z117（SP500 と DGS10 を1966年初期値から相互作用しながら60年共生成）
- モデルの全体像・数式・パラメータ決定根拠: `Z117_モデル詳細.md`
- コード: `model.py`（Config、CPU参照実装）+ `model_gpu.py`（PyTorch 実装、60年1本 ≈ 55秒）
- 出発パラメータ: `z117_config.py` の `Z117_PARAMS`（フラット辞書、147項目）

## 最終モデル: ZA-FINAL3

**パラメータ: `za_final_config.py` の `ZA_FINAL3_PARAMS`**（`ZA_LEAN_LM_PARAMS` からの差分4項目）。
代表結果は `results_fix4_7/O01_ef35/`（seed 1-3 と 10seed histinit）。

Z117 から出発し、(1)簡素化アブレーション → (2)スケール不変化 → (3)相関非対称/
リードラグ → (4)長期記憶 → (5)4課題ループ（終値・低分位leverage・極端相関・中心質量）
→ (6)レベル微調整、の順に反復して到達した構成。

## 反復改善で解いた課題

### 簡素化（アブレーション A〜E）

Z117 から5機構を除去（fear／ジャンプボラ連動／金利トレンド補正／メガ誘発／第2余震、
パラメータ8個削減）し3パラメータを再調整。score 0.293（Z117: 0.282、
ノイズフロア±0.01内で同等）。q999/sq_acf/rc_q05 はむしろ改善。

### スケール不変化（G）

投資ユニバースを制限し「銘柄あたり参加者数」を保存。×1〜×2 でスタイライズド
ファクトが不変。ハブ参加キャップ48は「×1ではほぼ縛らず×4では縛る」スケール選択性。

### 相関の非対称・リードラグ・長期記憶（H〜L）

7-8節の V字/ホッケー構造（極端分位でのみ相関が持ち上がる）、DGS10 の水準依存ボラ、
第2余震の持続化で SP500 lag2-20 と DGS10 |Δy| の ACF 裾を底上げ。
**時代分割の知見**: 実データ 7-8節の「弱い負ベース+極端分位のみ正」は
時代平均化の産物（負レジーム32年 vs 正20年）で、レジーム係数 κ=tanh((5.5−y)/1.5)
による金利水準での符号切替として再現。

### 4課題ループ（M〜P）

| 課題 | 状態 | 対処 |
|---|---|---|
| ④ 終値バイアス（histinit 全パスが実データを下回る） | ✅ | `anchor_drift` 校正 + 確率ドリフト（終値スプレッド×2） |
| ③ ボラ分位3-4の leverage 消失 | ✅ | `down_linear_coef=0.6` → dec3/4 = −0.042/−0.042（実 −0.041/−0.041） |
| ② SP500 極端分位での DGS10 相関欠如 | ⭕ | `dgs10_episode_flight=3.5`（エピソード限定 flight）→ リフト +0.10 |
| ① リターン中心質量の不足 | ✗ | 静穏フロアは複数ノイズ成分の合成でオープン課題（下記） |

**技術的発見**: 確率ドリフトを共有 rng から引くと以降の全乱数がずれてパス全体が
別抽選になる（共通乱数法の破壊）。専用 rng（seed+990001）に分離して解決。

**レベル微調整（P）**: O01 は histinit で SP500 年成長 7.83%（実7.45%）・
DGS10 平均水準 6.29（実5.92）と両方やや過大 → `anchor_drift` 0.00034→0.00032、
`dgs10_mr_center` 6.5→6.0。DGS10 平均水準 5.91（実5.92にほぼ一致）、SP500 は
実データのわずか下（多様性許容域）に着地。副作用なし。

## オープン課題（①中心質量）

実データ P(|r|<0.2%)=23%・静穏期フロア 0.0059 に対しモデルは 15%・0.0078。
フロアは exog ノイズ+個別ノイズ+粒度+参加ノイズの合成で、単一成分の状態依存化
（実現ボラ連動）では削れず、逆に活発期の増幅で裾が太る副作用が出た。
解決には「静穏レジームで全ノイズ成分を一括縮小する機構」が必要 — 次テーマ。
