### 解釈 — 何が本質だったか

アブレーションで確定した「効いている機構」:
- **危機の構造**（エピソード + プラトー + 負ドリフト）が尖度・sq_acf・dec10 leverage の本体
- **中規模ジャンプ**が裾の中間部と kurt の日常成分
- **市場アンカー + リバランス**が60年の長期安定性
- **非対称インパクト**（閾値+飽和）と**投資家別ストレス記憶**が leverage の分位構造
- **参加率日次ノイズ**が abs_acf1 の抑制
- **レジーム係数 κ（水準のみ）+ 双方向結合 + 外生成分分離**が株金利相関

一方、後付けの補正機構（fear、ボラ連動、金利トレンド補正、メガ誘発、第2余震）は
再調整で吸収可能な冗長性だった。

### E/F系: スケール感度（縮小・拡大の両側）

| 腕 | score | 症状 |
|---|---:|---|
| E06 企業 80→40 | 0.326 | abs1↑ q999↑ 相関q95崩れ |
| E07 投資家 60→30 | 0.313 | std↑ abs1=0.36（参加ノイズの平均化が失われる） |
| F01 企業 80→160 | 0.403 | dec10 −0.124 に弱化（分散投資効果で不均衡の影響が希釈） |
| **F02 投資家 60→120** | **0.477** | **kurt=60、std=0.009 — 大数の法則で取引由来ボラが死に、低ボラ状態に大ジャンプが乗る（旧「低ボラトラップ」の再来）** |
| F03 両方 (160/120) | 0.423 | 同様に崩壊 |

**結論: モデルはスケール不変ではない**。

機序の正確な記述（投資家は iid ではない点に注意）: 投資家は異質（非同分布）かつ共通シグナル
（観測・実現ボラ・金利・前日リターン）で相関するため古典的 LLN の前提は満たさない。しかし
集計注文フローを「共通シグナル駆動成分 + 個別乱数成分（参加ノイズ・売買 Bernoulli・サイズ）」に
分解すると、後者は共通シグナルで条件付ければ独立であり、独立・非同分布の配列に対する
Kolmogorov/Lindeberg 型の集中（iid 不要）により ~1/√N で縮む。本モデルの取引由来ボラの主体は
共通成分ではなく**有限 N の粒度ノイズ**（60人の売買の偶然の偏り）だったため、N 倍増で縮む。

実測: 外生フロア（取引死時の std≈0.009）を差し引いた取引由来成分は
N=30: 0.0107 → N=60: 0.0073（比 0.68 ≈ 1/√2）→ N=120: ≈0。
~1/√N スケーリングと整合し、N=120 では縮んだ粒度ノイズが「ボラ→リスク選好参加」の
発火閾値を下回り非線形に消灯する（Round3 のクジラ発見 = Gabaix 的 granularity と同根）。

現在のパラメータ（price_impact・参加率・リスク許容度）は N=60/n=80 に対する校正値であり、
スケールを変える場合は再校正が必須。

## Round G: 投資ユニバース制限によるスケール不変化

### 設計

E/F 系で判明した「投資家数 N を増やすと粒度ノイズ ~sqrt(H) が縮み内生ボラが死ぬ」問題への
構造的対応として、投資ユニバースを導入した:

- ユニバース = 専門セクター全社 + グラフ隣接企業 + ランダム5社、上限キャップ36
- スケール変更時は N/n 比 (0.75) とセクターサイズ (n/n_sectors = 10) を固定
- → 銘柄あたり参加者数 ≈ 26人 が ×0.5〜×4 の全スケールで一定 (実測 25.5〜27.0)
- 初期保有・リバランス目標もユニバース内に限定

### 校正の経緯

| Round | 内容 | 結果 |
|---|---|---|
| G1 | ユニバース + 4スケール掃引 | **全スケールで市場生存** (旧F02は×2で崩壊)。kurt 28-33・裾が過剰 |
| G2 | λ 0.019→0.013 | 逆効果 (発火閾値割れで kurt 43-64) → λ は維持 |
| G3 | tail 源の減衰 (危機σ0.046→0.038, jump2σ→0.014, メガ→0.18) | ×1 で kurt=20.2、dec10=-0.210/-0.197 (完璧)、**相関 q95 が 0.55 に正常化** (Z117 以来の課題解消) |
| G4 | 金利側の再校正 (σ0→0.030, drift_σ→1.0e-4) | ユニバース化で萎縮した金利パスの放浪を回復 (dy_std 0.048→0.058-0.065) |
| G5 | ×0.5/×4 の最終確認 | 下表 |

### 結論

- **×1〜×2 の範囲でスケール不変を達成**: 主要指標 (std/kurt/ACF/裾/leverage/相関) が
  パラメータ変更なしで保たれる。ユニバースなしでは×2で完全崩壊していた
- ×0.5 は市場が小さすぎてユニバース制限が実質無効化 (キャップ36 > 市場40) → 粒度過剰
- ×4 は市場は生存するが leverage と相関の負側が緩やかに弱化。残存するスケール依存は
  (a) ハブ銘柄の参加者数が n とともに増える (全セクターの隣接に入るため)、
  (b) 投資家別ストレス記憶の上位層の希釈、が候補。完全なスケール自由化には
  ハブ参加のキャップ等の追加設計が必要
- 副産物: 相関 q95 の過剰 (+0.80→+0.51) が解消。ユニバースの重なりが投資家共通ノイズの
  銘柄間相関を適正化したと解釈できる

**スケール可変版の確定設定**: `ZA_FINAL_V2_PARAMS` + `universe_mode='sector_graph'`
+ `universe_random_extra=5` + `universe_max_size=36` + 減衰A
(`disaster_sigma=0.038, exog_common_jump2_sigma=0.014, mega_crash_size=0.18`)
+ 金利再校正 (`dgs10_sigma0=0.030, dgs10_drift_sigma=1.0e-4`)。
スケール変更時は N/n=0.75 とセクターサイズ10を保つこと。

## Round H/I/J: 残課題3点のループ (相関非対称・スケールleverage・リードラグ)

### フェーズ① (Round H1-H5): 相関の非対称性

実データ構造 (7d窓): 極端分位で正 (≤1%: +0.33、≥99%: +0.24)、中間で弱負 (−0.08)。
モデルは全分位フラット (±0.2) だった。

- H1-H4: 単日超過分型の flight は「極端分位 ↔ 負側窓の深さ」の二律背反
  (7d窓相関は窓内の他6日が通常結合のままだと薄まる)
- **H5: 状態変数型 flight** — |r| > 2.2σ で点火し decay 0.80 で持続、持続中は
  当日リターン全体が正結合 (実データの「危機週を通じて株安→金利低下」に対応)。採用
- 補助機構: 正側 κ の非対称スケール 0.55 (tanh の低金利側の速い飽和の補正)、
  金利の平均回帰中心 5.5→6.5% (実データ平均 5.92% への整合)
- **知見**: 絶対水準は金利パスのレジーム構成が支配 (seed3 は負支配で mid=−0.20、
  seed1 は正支配で +0.14)。実データの点は「32年高金利」の1実現の構成であり、
  点一致の追求はレジーム構成の固定 = 過適合。形状 (極端−mid のリフト +0.15〜+0.3) を
  機構で作り、水準は seed 分布として評価する

### フェーズ② (Round I1): スケールでの leverage 維持

G系の残課題 (×4 で dec10 −0.21→−0.15 に希釈) への対応。

に回復 (×1 水準 −0.204 の93%)。×1 への副作用なし。仮説確定。

**実データの「弱い負ベース + 高ボラ分位のみ正」は時代平均化の産物**であり、
時代内の構造は「高ボラほどその時代のレジーム相関が増幅」。モデルの seed 別は
seed1/2 = 正レジーム型 (低金利滞在61-68%)、seed3 = 負レジーム型 (17%) として
時代内構造を既に正しく再現しており、水準もモデルの方がむしろ小さい
(時代内mid: モデル±0.17-0.18 vs 実±0.25-0.27) ことを確認した。

→ フェーズ①の flight (極端日は常に正) と正側κスケールは「時代平均のアーティファクトを
機構で追った過剰装備」であり、J11 の副作用 (abs1/sq1膨張、rc_q05浅化) に見合わない。

## Round L: ACF全形状の改善 (長期記憶成分)

## Round M/N/O: 4課題ループ (終値バイアス・低分位leverage・極端相関・中心質量)

### ④ 終値バイアス (M系) — 解決

全 histinit パスが実終値を下回っていた原因は決定論的:
anchor_drift=0.00025 (年率6.5%) < 実成長 7.7%、加えて危機負ドリフトが −1.2%/年。
→ drift 0.00034 で実効成長 7.1〜8.1%。**パスごと確率ドリフト** (AR(1), σ=1e-6) で
終値の多様性も実現 (±1%/年 → 60年で×2 のスプレッド)。

**技術的注意 (M3-M4)**: 確率ドリフトを共有 rng から引くと以降の全乱数がずれ、
パス全体が別抽選になる (共通乱数法の破壊)。M3 で見えた「σ=5e-7 でも dec10 が
−0.04 変化」はこのアーティファクト。専用 rng (seed+990001) に分離して解決。

### ③ 低中分位 leverage (M系) — 解決

leverage 機構 (asym_pi/ストレス) は neg² と閾値で「意味のある下落」だけに反応する
設計のため、dec3-5 の滑らかな応答の裾が構造的にゼロだった。
`down_linear_coef=0.6` (down_var とストレスの蓄積に + 0.6×neg×σ0 の線形項を併設。
小さい neg では neg² に匹敵、大きい neg では無視できる) により
**dec3/dec4 = −0.042/−0.042 (実 −0.041/−0.041)**。初回試行 (係数0.08-0.15) は
線形寄与が down_var ベースラインの1%未満で不発 — 規模の教訓。

### ② 極端分位の相関 (N/O系) — 解決 (エピソード限定flight)

- N1 (レジーム符号付き増幅): 不成立。増幅は「その時々のκ」に従うため、
  危機がそのパスの高金利期に落ちると極端分位が強い負になる (時期配置は seed 運)
- **N2/O1 (エピソード限定 flight, ef=3.5)**: disaster_intensity > 0 の間だけ
  当日リターンに正結合。実データの構造 — 通常の高ボラ日はレジーム相関、
  本物の暴落 (1987) は高金利時代でも金利急落 — と一致。
  負レジーム seed でも暴落週に極端分位が mid を +0.1〜0.28 上回る
- 副案 (exog ボラ連動との併用) はリフト +0.28 まで強まるが、ボラ増幅ループが
  復活し abs1=0.35/q999=0.12/dec10=−0.15 と広範に劣化 → 棄却

### ① 中心質量 (O系) — 未解決 (診断のみ)

実データ: P(|r|<0.2%)=23.1%、静穏期フロア (rolling std 下位10%) = 0.0059。
モデル: 15%、0.0078。共通ノイズの状態依存化 (実現ボラ連動) を試したが
フロアは動かず — **フロアは exog ノイズ+個別ノイズ+粒度+参加ノイズの合成**で、
単一成分の連動では削れない。「静穏レジームの全成分スケーリング」が必要
(取引・個別・共通を一括で静穏時に縮める機構) — オープン課題。

### 最終形: ZA-FINAL3 (`ZA_FINAL3_PARAMS`)

= ZA-LEAN-LM + drift 0.00034 + 確率ドリフト σ1e-6 + lin 0.6 + episode_flight 3.5

| 課題 | 状態 |
|---|---|
| ④ 終値バイアス | ✅ 成長率 7.1-8.1%、終値スプレッド ×2 |

### レベル微調整 (Round P) — SP500/DGS10 とも実データより少し過大

histinit(10seed) で診断: SP500 年成長 **7.83%**(実7.45%, +0.38%/年 → 終値中央値
9572 vs 実7501 で28%高)、DGS10 平均水準 **6.29**(実5.92)。両方が系統的に上振れ。
原因は決定論的で、④で上げた `anchor_drift`(0.00034) が過大、`dgs10_mr_center`(6.5)
が実データ平均5.92より高い引力点。

- **P01 (drift 0.00032 / mr_center 6.0)** 採用: DGS10 平均水準 **5.91**(実5.92 一致)、
  SP500 年成長 histinit中央値 ~7.3%(実のわずか下 = 多様性許容域)。
  副作用ゼロ: abs/sq_acf1=0.30/0.28・q999=0.092・dec10=−0.189 いずれも O01 と不変。
  ② 極端リフトは +0.08→+0.10 と**むしろ改善**(金利低下で低金利=正相関レジーム滞在増)。
- P02 (drift 0.00031 / mr 5.8): 成長 ~7.1%・DGS10 5.81 と両方下げすぎ → 棄却。

これで ④(終値) は「バイアス除去 + レベル整合 + 多様性」の3点を満たす最終形に。

## Round Q〜Z2: 「最近ほど大変動」の根治 — 富の凝縮の発見と解決

### 診断の系譜 (ユーザー指摘「実データと比較にならない大変動が直近に多発」)

1. **Q**: 危機の深さ (disaster_mu×plateau) を修正 → worst_5d/21d は実データ一致。
   だが図の印象は変わらず。
2. 時代別分解で **暴騰暴落の頻度が時代偏在** (>50%/年: 実は全時代~0.8%で一定、
   モデルは前半0%/直近3.2%)、**平穏ボラ床が経年ラチェット** (0.71→1.02、実は横ばい)。
3. **R**: trend_weight (モメンタム) 仮説 → 3倍下げても不変。**棄却**。
4. **S**: ベースノイズ削減 → std/max12m は改善するが「一律縮小」で偏在は不変。
5. **T**: ボラEWMA固定アンカー (マクロ介入、診断用) → **床が全く動かず棄却**。
   realized_var は結果の反映であって原因ではないと判明。
6. 内部状態の直接計測で切り分け: asym_pi(自己正規化済)・ストレス(平穏0)・
   現金/保有比率(安定)・score(横ばい)・rebalance(無効) を順に棄却。
   人数合意度は横ばいなのに金額imbalanceだけ飽和 →
   **富の凝縮 (wealth condensation)**: 60年で実効投資家数 14.8→1人 (HHI 0.995)。
   1人のホエールの売買が金額imbalanceを支配し内生ボラ床を押し上げていた。

### 対処の試行 (U〜Z2)

- **U (資本回転・即時交代)**: ユーザー設計 (幾何寿命staggered、退出→現金参入→
  パラメータ再ドロー)。実装バグ2件の教訓:
  (a) 参入資金を富中央値にすると退出売り圧との非対称でネット買い資金が複利注入され
      **価格が指数発散** → 現金中央値スケールに修正。
  (b) **rho_per_dim (信念再帰の派生テンソル) の更新漏れ** → 新phi+旧rho>0.97 で
      float32 発散 (t=1433)。派生テンソルの再構築が必須。
  → 修正後も全seedで暴騰増加。**ホエール即時消滅 = 売り供給の瞬間蒸発**が原因。
- **V (段階的清算)**: 63-126日かけ清算しても、退出時点で富の99%を握るホエールの
  清算はどの速度でも市場地震 (worst21 -0.46〜-0.59)。**凝縮「後」の対処は不可能**。
- **W (キャパシティ制約)**: 注文×(富シェア×n)^(-γ)、γ=0.5 — 実市場の大規模
  ファンドの執行制約に対応するミクロ機構。**床ラチェット完全解消 (1.46→0.95)、
  バブル頻度 1.7%→0.3%**。凝縮の市場支配と複利加速を創発的に抑える。
- **X**: γで大人しくなった分ベースノイズを FINAL4 水準へ復元 (std/kurt/worst21回復)。
- **Y**: drift 0.00030 で成長 0.074(実0.0745)。残: leverage -0.14 (γがホエールの
  投げ売り=leverage増幅源も絞った)。asym_pi/stress強化は飽和ぎみで小効果。
- **Z1**: 売りγ常時解放 → leverage完全復元 (-0.209=実) だが床ラチェット復活。
  **売り自由度は leverage の源かつラチェットの源** — 常時解放では両立不能。
- **Z2 (採用)**: **状態依存ファイアセール** — 下方ストレス比 down_var/(realized/2)
  > 0.8 で売りγを解除。「平時は執行制約・危機は投げ売り」という実市場の非対称を
  そのまま実装。床抑制と leverage が両立。
