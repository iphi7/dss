# S_goal01_variant_S_tail_events 検証レポート

## 目的

R03 seed2 を分析した結果、以下が見えました。

1. raw return ACF は改善している。
2. `|r|` の ACF はまだ少し高いが、Q系ほど悪くない。
3. leverage は notebook の高ボラ十分位では十分出ている。
4. 一方で、最上位分位の立ち上がりが実データより弱い。
5. 全期間尖度も不足している。

このため、R03をベースに「ACFを増やさず、例外的な特大ジャンプだけを補う」検証を行いました。

## 分位数の確認

`stylized_facts_analysis.ipynb` の3番の分位数は、下からの累積割合です。
`q=1` 付近は最大級の変動幅を意味します。

5番の分位1〜10は、当期絶対リターン `|r_t|` の十分位です。
1が低ボラ群、10が高ボラ群です。
各点は `0.1, 0.2, ..., 1.0` の点ではなく、各10%区間のグループです。

## 実装

`market_tail_jump_*` を追加し、企業全体に共通する稀な市場ジャンプを価格形成式に足しました。

$$
r_{j,t} = r_{j,t}^{\mathrm{base}} + J_t.
$$

この $J_t$ は状態を持たず、基本的に iid です。
したがって、fear や activity impact のように ACF を長く押し上げにくい設計です。

Round3以降では tail jump 専用RNGを導入しました。
これにより、R03の基礎乱数列を変えずに、ジャンプだけを追加できます。

## 結論

`S11_disaster_mix seed2` が現時点では最も良いです。
R03 seed2で問題だった最上位tailは改善し、`abs_acf5` も実データに近いです。
raw return ACFも悪化していません。

一方、全期間尖度はまだ実データに届いていません。
また、`sq_acf5` が低くなりすぎており、ジャンプが完全に iid すぎる可能性があります。

## 次の改善案

次は、ジャンプ後にだけ2〜3日程度の非常に短い余韻を入れるのが良さそうです。
例えば

$$
\sigma_{t+1}^{\mathrm{event}}
= \rho_e \sigma_t^{\mathrm{event}} + c |J_t|,
\quad \rho_e \in [0.2, 0.5]
$$

のように、長期ACFを作らない短期イベントボラを足します。
これにより、`sq_acf5` と尖度を少し戻しつつ、Q系の過剰ACFを避けられる可能性があります。
