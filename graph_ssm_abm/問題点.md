## 1. カルマンフィルタを使う意味があるか / 取引スコアが将来予測ベースになっていない

### 問題（カルマン）

毎タイムステップ、投資家は全企業の観測値 $y_j$ を受け取り、カルマン更新を行う。

$$
K^{(i)}_j = \frac{P^{(i)-}_j}{P^{(i)-}_j + R_i}, \qquad
\hat{x}^{(i)}_j \leftarrow \hat{x}^{(i)-}_j + K^{(i)}_j (y_j - \hat{x}^{(i)-}_j)
$$

カルマンゲイン $K$ が大きい場合、$\hat{x}^{(i)}_j \approx y_j$ になる。状態推定が毎日ほぼ観測値にリセットされており、グラフ $W_i$ を通じた予測伝播が意味を持たない。**→ variant_F で確認済み（差なし）**

### 問題（スコアが現在推定値ベース）

より根本的な問題として、取引スコアが「現在の推定値」ベースになっており、「来期予測」に投資家の個性が反映されていない。

```python
pred = a_i @ estimates[i]           # W_i・belief_phi/rho を使った来期予測
updated = pred + gain * (y - pred)  # predはカルマンの中間変数として消費
score = value_weight * updated + ...  # スコアは updated（≈ y）ベース
```

`pred`（グラフを使った将来予測）がスコアに入っていないため、投資家が異なるグラフを持っていても取引行動に差が出ない。

### 改善方向

カルマンを廃止し、取引スコアを来期予測ベースに変更する：

```python
current = y   # 観測をそのまま現在推定とする
pred_next = belief_phi * current + belief_rho * (W_i @ current)  # 来期予測
score = value_weight * pred_next + trend_weight * (pred_next - current) + ...
```

$W_i$ の差異が `pred_next` の差異として直接スコアに入り、取引行動を分化させる。

### 検証方針

**variant\_F\_no\_kalman** （完了）: カルマン更新の有無の差なし → カルマン不要を確認。  
次のステップ: 来期予測ベーススコアの実装と効果検証。

## 2. 観測モデルが H = I（構造的不可観測成分がない）

### 問題

現在の観測モデルは：

$$y_j = x_j + \varepsilon_j, \quad \varepsilon_j \sim \mathcal{N}(0, R_i)$$

観測ノイズ $\varepsilon_j \to 0$ にすれば $y_j = x_j$ が完全に得られる。
現実には、IR情報などの公開情報からは企業の潜在状態が完全に分からない（内部情報・未公開の競争優位性など）。公開情報だけで見えない**構造的不可観測成分**が存在するはずである。

### 改善方向

潜在状態を公開成分と非公開成分に分離する：

$$x_j = x_j^{\text{pub}} + x_j^{\text{priv}}, \qquad y_j = x_j^{\text{pub}} + \varepsilon_j$$

- $x_j^{\text{priv}}$ は直接観測できない
- ネットワーク隣接企業の公開観測を通じてのみ間接推定できる
- 投資家が正確な $W_i$ を持つほど $x_j^{\text{priv}}$ の推定精度が上がる
- カルマンゲインによる毎日の修正が及ばないため、グラフ多様性が蓄積する

## 3. 主観グラフの非専門セクター保持率が高すぎる

### 問題

現在の実装：

```python
base_keep = rng.uniform(0.15, 0.55)        # 非専門セクターの保持率
expert_keep = base_keep + expert_bonus      # 専門セクターの保持率
```

非専門セクターでも平均 36% のエッジが残る。「セクター3しか知らない」投資家ではなく、
「全セクターをぼんやり知っており、セクター3だけ少し詳しい」という生成になっている。
全体でエッジ数を確認すると min 153 / max 356（2.3倍の開き）はあるが、構造的偏りではなくランダムな脱落に過ぎない。

### 改善方向

非専門セクターの保持率を大幅に下げ、専門セクターとの差を際立てる：

```python
base_keep = rng.uniform(0.01, 0.08)         # 非専門は 1〜8%
expert_keep = rng.uniform(0.80, 0.98)        # 専門は 80〜98%
```

さらに「複数セクターを専門とする」「グラフを全く持たない純粋チャーティスト」なども導入できる。

ただし、この問題は **問題2（観測モデル）と問題1（カルマン更新）が解決されないと意味がない**。
グラフの誤差が毎日観測更新で消されるうちは、グラフの構造的多様性があっても価格形成に伝わらない。

## 4. 価格形成に真の潜在状態 x が直接入っている

### 問題

```python
firm_return = (
    config.price_impact * imbalance
    + config.latent_price_beta * x          # 真のxが直接リターンに入る
    - 0.0018 * np.maximum(-x, 0.0)          # 非対称性にも真のx
    + common_noise + noise
)
market_stress = np.mean(np.abs(x)) + ...    # ボラティリティ計算にも真のx
```

投資家の推定 $\hat{x}^{(i)}$ を介さずに、真の $x$ が神の視点から価格に影響している。
これは「市場価格が情報を完全に集約している」状態に近く、グラフ推定精度が価格に伝わりにくい。

### 改善方向

価格形成をより純粋に注文不均衡ベースにする（$x$ の直接介入を除去または縮小）：

```python
firm_return = (
    config.price_impact * imbalance     # 注文不均衡のみ
    + common_noise + noise
)
```

ボラティリティ計算の `market_stress` も `imbalance` ベースに統一する。

## 5. 対角カルマン近似（クロス企業共分散の無視）

### 問題

現在のカルマンフィルタは企業ごとに独立にスカラー更新している（対角近似）。
本来、企業 $j$ の観測 $y_j$ は隣接企業 $k$ の状態推定も更新できるはずだが、クロス企業共分散 $P_{jk}$ を持たないため、この伝播が起きない。

$W_i$ を正確に知っている投資家だけが $y_k$ から $x_j^{\text{priv}}$ を推定できるという**グラフ知識の価値**が、この近似によって完全に消失している。

### 改善方向

企業数 $n=80$ のフル共分散行列（$80 \times 80$）を各投資家が持つのは計算コストが高いため、
構造的な近似として「セクター内はフル共分散、セクター間は独立」などのブロック共分散近似が考えられる。

## 6. 全投資家が全企業の観測値を同時に受け取る（情報伝播の時差がない）

### 問題

現在のループ：

```python
y = s + noise   # 全80企業分が同時生成

for i in investors:
    est_h = belief_rho_h * (W_i @ y)   # 全員が同じ y を同時に使う
    pred_next = ...
    score = f(pred_next)
```

ハブ企業 $j$ に大きなショックが来たとき、全投資家が **同時に $y_j$ を観測**する。
グラフ $W_i$ の知識がある投資家は「$k$（$j$ の隣接先）の来期が上がる」と予測できるが、
**全員が同時に情報を得るため、反応に時差が生まれない。**

本来あるべき構造：

| タイプ | 時刻 $t$（ショック発生） | 時刻 $t+1$ |
|---|---|---|
| ハブ近傍をよく知っている | $y_j$ を見て隣接 $k$ を先回り購入 | 確認して追加購入 |
| ハブを知らない | 反応できない | $y_k$ が上がってから初めて購入 |

この時差のある買い圧力が（|r|の）自己相関やモメンタムを生む源泉だが、現在は存在しない。

また、60人の異なる $W_i$ による注文を合計すると大数の法則的に：

$$\sum_i f(W_i y) \approx N \cdot f(Wy)$$

となり、グラフ多様性が集計レベルで平均化される。この二重の問題により、
variant_E〜H まで一貫してグラフ多様性がスタイライズドファクトに影響しなかった。

### 改善方向：部分観測（投資ユニバースの限定）

各投資家が観測できる企業を**投資ユニバース** $O_i$ に限定する：

$$y_j^{(i)} = \begin{cases} y_j & j \in O_i \\ 0 \text{（または前期値）} & j \notin O_i \end{cases}$$

$O_i$ の構成例：
- 専門セクターの全企業
- $W_i$ 上で直接つながっている企業（隣接ノード）
- それ以外は観測不能

これにより：
- ハブ $j$ の変化は $j \in O_i$ の投資家のみが即座に知る
- $j \notin O_i$ の投資家は伝播後の $y_k$（$k \in O_i$）で遅れて気づく
- **時差のある買い圧力** → リターンの自己相関・モメンタム・ボラティリティクラスタリング

## 7. 非公開成分 h の不安定性（base2 で発覚）

### 問題

B_base1_H_variant_H_pub_priv で $h$ の遷移行列

$$A_h = \phi_h I + \rho_h W$$

のスペクトル半径が $\phi_h + \rho_h = 0.90 + 0.35 = 1.25 > 1$ となっており、$h$ が指数的に発散する。firm_snapshots で確認すると day=252 で $|h| \sim 10^{20}$、day=1259 で $|h| \sim 10^{123}$。

$h$ は観測にも価格形成にも直接入らないため sp500 リターンは一見正常だが、投資家スコアに `est_h = belief_rho_h * (W_i @ y)` として間接的に流れ込む（ただし y は安定な s に基づくため est_h 自体の爆発はないが設計として誤り）。

### 解決策

$$\phi_h + \rho_h < 1 \text{ を保証する}$$

例: $\phi_h = 0.65,\ \rho_h = 0.30 \Rightarrow 0.65 + 0.30 = 0.95 < 1$（安定）

**→ ✅ 解決済み（base2 モデルパラメータ修正済み）**

## 8. market_stress から x を除去したことによる |r| ACF の低下

### 問題

| バリアント | market_stress | absacf5 |
|---|---|---|
| variant_G | `mean(\|x\|) + 0.6 * \|mean(imbalance)\|` | 0.069 |
| base2/H | `mean(\|imbalance\|)` のみ | 0.009 |

G では自己相関 $\phi_s = 0.82$ を持つ $x$ が GARCH のベース分散を持続的に駆動していた。base2 でこれを除去したことで、GARCH の持続性源が `prev_common_noise^2` だけになり弱くなった。

真の $x$ を使うのは「神の視点」なので望ましくないが、代替の持続的ドライバーが必要。

### 解決策

市場全体のコンセンサス推定値（投資家の推定値の平均）でボラティリティを駆動する：

```python
# 真のxの代わりに市場の集計推定値を使う（神の視点ではない）
agg_est = mean_over_investors(y_i + belief_rho_h * W_i @ y_i)
market_stress = mean(|agg_est|) + 0.6 * |mean(imbalance)|
```

$y$ は安定（s ベース）なので agg_est も安定。かつ $y$ は $s$ の AR(1) の影響を受けるため持続性がある。

**→ ✅ 解決済み（base2 モデルに集計推定値ベースの market_stress を実装済み）**

## 9. 企業状態変数の次元が小さすぎる（スカラー2つ）

### 問題

現在の企業 $j$ の潜在状態は：

$$x_j = (s_j,\, h_j) \in \mathbb{R}^2 \quad \text{（公開スカラー1次元 + 非公開スカラー1次元）}$$

現実の企業状態は多次元であり、財務健全性・収益性・成長性・内部情報・マクロ感応度など多くの変数が時々刻々と変化する。スカラー1次元では「企業の状態」として単純すぎる。

### 多次元化で得られるもの

状態を $x_j \in \mathbb{R}^d$（$d \geq 5$ 程度）にすると：

1. **投資家ごとに観測できる次元が異なる**：財務アナリストは財務次元のみ、セクター専門家は業務次元を詳しく知る → 観測行列 $C_i \in \mathbb{R}^{k \times d}$ が投資家ごとに異なる
2. **次元ごとに異なるネットワーク伝播パターン**：需要は川上→川下、財務健全性は資金調達ネットワークで伝わる
3. **LLN の自然な破綻**：投資家が観測する次元が異なるため、単純集計しても平均化されない成分が残り、グラフ多様性が集計量に現れる

### 改善方向

```python
# 企業状態: d次元ベクトル
x_j ∈ R^d   # 例: d=5 (財務, 収益性, 成長性, 需要, 内部情報)

# 投資家iの観測: 自分が知っている次元への射影
y_i_j = C_i @ x_j + noise    # C_i ∈ R^{k×d}, 投資家ごとに異なる
```

ネットワーク伝播も次元ごとに異なる行列 $W^{(d)}$ を持てる。この変更は設計の根幹に関わるため、ベースモデルの再設計が必要。

## 10. 時価総額の多様性が不十分（指数への影響が均等すぎる）

### 問題

variant_J のスケール検証で `n_firms=40` にすると absacf5 が 0.034 → 0.118 に大幅改善した。これは「企業数が少ない」ことそのものではなく、**1社あたりの指数ウェイトが大きくなり、ハブ企業のショックが指数に直接響きやすくなった**ことが本質的な原因である可能性が高い。

つまり効いているのは「企業価値（時価総額）の多様性」であり、少数の大企業が指数を支配する構造こそが重要かもしれない。

現状の時価総額生成：
```python
shares = rng.lognormal(mean=0.0, sigma=0.8, size=n)        # 中程度の多様性
firm_prices ≈ initial_sp * lognormal(0, 0.12)               # ほぼ均一
market_cap = firm_prices * shares                            # shares に支配
```

実データの S&P500 では上位5社だけで指数の約25%を占める超偏在分布だが、sigma=0.8 程度ではそこまで極端にならない。

### 改善方向

時価総額の分布をより現実的なべき乗則に近づける（例: Zipf 分布、Pareto 分布）：

```python
shares = rng.pareto(a=1.0, size=n)   # ヘビーテール（上位企業が支配）
```

または、`n_firms=80` のままでも sigma を大きくして極端化する。合わせてハブ企業（BA グラフ上の高次数ノード）と時価総額を相関させる（大企業ほどハブになる）とより現実的。

## 10. σ_mkt（基準市場ボラティリティ）が固定値

### 問題

現在 `σ_mkt = 0.006`（= `market_vol`）は固定パラメータ。これは GARCH のベース分散 $\bar{\sigma}^2_t$ のスケールを決める定数として使われている：

$$\bar{\sigma}^2_t = \sigma^2_{\text{mkt}} \cdot (1 + 6\,\text{market\_stress}_t + \cdots)$$

しかし市場全体の長期的なボラティリティ水準は時代によって異なる（低ボラ相場 vs VIX スパイク期など）。履歴データから推定すべき量を固定値にしているのは不適切。

### 改善方向

入力の `output.csv`（実データ）からローリング標準偏差等で推定し、初期値として与える：

```python
hist_vol = output_df["sp500"].tail(252).std()   # 直近1年の実現ボラ
config.market_vol = hist_vol
```

または、シミュレーション開始時点の実データ分布に合わせてキャリブレーションする。

## 11. 投資家の行動に時刻依存性がなく、大数の法則が成立してしまう

### 問題

大数の法則（LLN）は $X_1, X_2, \ldots, X_N$ が i.i.d.（独立同分布）である場合に $\bar{X}_N \to \mu$ を保証する。

現状の投資家はパラメータは異質だが、各時刻 $t$ において**全員が同じ $y_t$ を受け取り、独立に売買決定する**（時刻依存の相関がない）。このため：

$$\text{imbalance}_j(t) = \frac{1}{N}\sum_i f_i(y_t) \approx \mathbb{E}_i[f_i(y_t)]$$

と、LLN が働いて集計量が安定化し、グラフ多様性・投資家異質性が価格に現れにくくなる。

### 改善方向

LLN を破綻させるには、投資家間に**時刻依存の相関**を導入する：

- **情報の時差（部分観測 variant_I の方向）**: 投資家が異なる時刻に情報を受け取る → i.i.d. 仮定が崩れる
- **模倣行動・ハーディング**: 前期の市場全体の動きを見て行動を修正する → 共通ノイズが入り i.i.d. でなくなる
- **資産規模の不平等**: 大口投資家が市場を支配 → 少数の投資家の非 i.i.d. 行動が集計量に残る

## 12. c_t が市場活動に依存しており「外乱」として機能していない

### 問題

現在の c_t の分散（= market_var）は market_stress 経由で投資家活動に強く依存している：

$$
\bar{\sigma}^2_t = \sigma^2_{\text{mkt}} \cdot (1 + 6 \cdot \text{market\_stress}_t + \cdots)
$$

$$
\text{market\_stress}_t = \overline{|\hat{x}^{(i)}|} + 0.6\,|\overline{\text{imbalance}}|
$$

`garch_stress_scale=6.0` では market_stress が 0.05→0.20 と変動すると base_var が 1.3× → 2.2× (σ²_mkt) と約 1.7 倍変動する。
c_t は「ときどき跳ねるランダムな外乱」ではなく「市場活動によって増幅されるノイズ」になっており、
ボラクラの主要因が c_t の市場感応的な増幅という設計上不適切な経路になっている。

### 改善方向

c_t の分散を市場活動から切り離す（`garch_stress_scale=0`）。
ボラクラは別の内生的メカニズム（問題13）から生む。

## 13. 投資家のリスク選好がボラティリティ水準に反応しない

### 問題

現在の投資家は `risk_tolerance`, `temperature` などのパラメータが固定であり、
現在のボラティリティ水準にかかわらず同じ強度で売買する。

現実には：
- **リスク選好型投資家**：高ボラ期に取引閾値が下がり、より大きなポジションを取る
- **リスク回避型投資家**：高ボラ期に縮小し、様子見になる

リスク選好型が数または資産規模で優勢な場合、正のフィードバックが生じる：

$$
\text{高ボラ} \to \text{リスク選好型が積極売買} \to \text{imbalance 増大} \to \text{価格変動大} \to \text{高ボラ持続}
$$

これはボラクラの内生的メカニズムとして自然で、現実の行動ファイナンス的根拠がある。

### 改善方向

投資家に `vol_sensitivity` パラメータを追加：

```python
vol_ratio = prev_market_vol_t / config.market_vol  # baseline との比
vol_factor = clip(1.0 + vol_sensitivity × (vol_ratio - 1.0), 0.05, 4.0)
effective_rt = risk_tolerance × vol_factor × (0.25 + conviction)
```

`vol_sensitivity ~ N(+0.40, 0.60)` (正寄り) → 市場全体として弱いリスク選好バイアス。

これと c_t の外生化（問題12）を組み合わせることで：
- c_t = 固定分散の外乱（外生ショック）
- ボラクラ = 投資家のリスク選好フィードバック + GARCH c_t 持続性（内生的機構）

## 14. 主観グラフの「辺の有無」と「辺重み精度」が分離されていない

### 問題

現在の主観グラフ比較では、主に

$$
W_i = W \quad \text{vs.} \quad W_i \neq W
$$

という形で、投資家が企業グラフを知っているかどうかを見ている。しかし、実際には投資家のグラフ知識には少なくとも2つの異なる精度がある。

1. **トポロジー精度**：どの企業同士に辺があるかを知っているか
2. **重み精度**：その辺がどれだけ強い影響を持つかを正しく知っているか

現状の `partial` / `perfect` 比較では、辺の欠損・偽辺・重み誤差が混ざっているため、どの要素が効いているのか分離できない。

真の企業グラフを

$$
W = (w_{jk})
$$

投資家 $i$ の主観グラフを

$$
W_i = (\tilde{w}^{(i)}_{jk})
$$

とすると、現在の `perfect` は

$$
W_i = W
$$

であり、トポロジーも重みも完全一致している。一方 `partial` は、欠損・偽辺・重み誤差が同時に入る。

### 改善方向

グラフ知識の精度を以下のように分解して検証する。

| 条件 | 辺の有無 | 辺の重み | 目的 |
|---|---|---|---|
| `zero_graph` | 知らない | なし | グラフ自体の必要性 |
| `topology_only` | 真の辺集合を知る | 一様重み | トポロジーだけで十分か |
| `topology_noisy_weight` | 真の辺集合を知る | 真の重みにノイズ | 重み精度の影響 |
| `partial_edges_noisy_weight` | 欠損・偽辺あり | 残った辺にもノイズ | 現実的な主観グラフ |
| `perfect_graph` | 真の辺集合を知る | 真の重みを知る | 上限性能 |

#### topology only

辺集合だけは正しいが、重みは分からない場合：

$$
\tilde{w}^{(i)}_{jk}
=
\begin{cases}
1/d_j, & w_{jk} > 0,\\
0, & w_{jk} = 0.
\end{cases}
$$

これは「どこと繋がっているか」は知っているが、「どの隣接企業がどれだけ重要か」は知らない投資家に対応する。

#### noisy weight

辺集合は正しいが、重み推定に誤差がある場合：

$$
\tilde{w}^{(i)}_{jk}
\propto
w_{jk}\exp(\epsilon^{(i)}_{jk}),
\qquad
\epsilon^{(i)}_{jk} \sim \mathcal{N}(0, \sigma_w^2).
$$

$\sigma_w$ を変えることで、重み推定精度を連続的に制御できる。

#### partial topology + noisy weight

辺の欠損もあり、残った辺の重みもズレる場合：

$$
\tilde{w}^{(i)}_{jk}
=
 m^{(i)}_{jk} w_{jk}\exp(\epsilon^{(i)}_{jk})
$$

$$
m^{(i)}_{jk} \sim \mathrm{Bernoulli}(p^{(i)}_{jk}).
$$

専門セクターに関わる辺では $p^{(i)}_{jk}$ を高く、非専門では低くする。

### 含意

もし `topology_only` と `perfect_graph` の差が小さければ、辺重み精度は重要ではなく、辺集合だけで十分ということになる。

逆に、`topology_only` と `topology_noisy_weight` / `perfect_graph` の差が大きければ、企業間影響の強さをどれだけ正確に推定できるかが重要になる。

もしこれらを試しても差が小さい場合、問題はグラフ知識の精度ではなく、そもそも現在の価格形成や推定式における

$$
W_i y_t
$$

の寄与が小さすぎることを意味する。その場合は、private 推定を scalar ではなく dimension-wise にする、非専門投資家の観測をより制限する、グラフ経由でしか見えない状態次元を増やす、といった設計変更が必要になる。

## 15. leverage effect が再現できない（実データは負、モデルは正またはゼロ）

### 問題

実データの leverage 係数（$\mathrm{corr}(r_t,\,\sigma_{t+1,\ldots,t+20})$）は $-0.043$ だが、全モデルでほぼゼロか正になる（O19: $+0.002$）。

leverage effect とは「下落後にボラが上昇する」非対称性である。現実には下落が恐怖・損失回避を引き起こし、売り圧力の増大 → 流動性低下 → ボラ上昇というフィードバックが起きる。また金融レバレッジ効果（株価下落で負債比率上昇 → 株式リスク上昇）も一因とされる。

現状モデルでは：
- c_t は外生で非対称性がない
- 価格インパクトは買いと売りで対称
- 投資家の損失後の行動変化がない

そのため、上昇時も下落時も同程度のインパクトになり、leverage が出ない。

### 改善方向

複数の非対称化機構を候補として検証する（`P_base5_variant_P_leverage`）：

1. **GJR-GARCH 的 c_t 分散増幅**：下落後に c_t の $\sigma$ を一時的に上昇させる。追跡 EWMA: `down_var_t = decay * down_var_{t-1} + (1-decay) * max(-r_{SP,t}, 0)^2`、`sigma_c_t = sigma_c * sqrt(1 + gjr_scale * down_var_t / sigma_c^2)`。
2. **非対称価格インパクト**：下落後、売り方向のインパクト係数を増幅させる。市場下落 EWMA を追跡し、`lambda_t = lambda_0 * (1 + asym_pi_scale * down_var_t / sigma_ref^2)`。
3. **損失トリガー強制売り（stop-loss）**：下落後、損失回避型投資家が保有株を売り増す。`sp_ret_{t-1} < 0` のとき、`vol_sensitivity < 0` の投資家の sell prob を増幅する。
4. **非対称流動性クラッシュ**：現在のクラッシュは取引量が多ければ発動するが、売り圧力優勢時のみ発動するよう変更する。

## 16. skew が正確に再現できない

## 20. グラフジャンプの企業間連動が弱く、クラスタ大打撃を表現しきれていない

### 問題

現状のグラフジャンプは

$$
\beta_t = z_t + \lambda Wz_t + \lambda^2 W^2z_t
$$

で exposure を作り、企業別ジャンプ

$$
\Delta r_{j,t}^{event} = \beta_{j,t} J_t
$$

を足している。

しかし、正規化や clip のため、実際には「グラフ上に薄く分散する」傾向がある。
そのため、ある企業クラスタが大打撃を受け、その周辺企業にも大きな同方向ショックが伝播する、という現象を十分に表現できていない。

現実的には、例えばサプライチェーン・金融セクター・大型テッククラスタなどで、特定クラスタ内の企業が同時に大きく動くことがある。
現在の実装では、局所性はあるがクラスタ内の強い同期が弱い。

### 改善方向

次に試すべき方向：

1. shock source 近傍の exposure を平均1正規化ではなく、クラスタ内で高く保つ。
2. source から距離1〜2の企業には同方向ジャンプを強く入れる。
3. クラスタ外には急速に減衰させる。
4. `W^k z` の単純和ではなく、閾値付き / community-based propagation を使う。
5. イベント後の余韻も市場全体ではなく、同じクラスタ内だけに1〜2日残す。

目的は、一様市場ジャンプではなく「グラフ上の局所的な集団ショック」として tail を作ること。
