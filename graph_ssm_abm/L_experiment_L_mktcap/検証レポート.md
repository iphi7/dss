# L系検証レポート: 時価総額の偏在化

## 目的

base3 (d=20) をベースに時価総額の偏在化（Pareto 分布 + BA次数相関）を実装し、
スタイライズドファクトへの影響を検証する。

## 実装概要

### 時価総額生成
```
base_shares ~ Pareto(a) + 1.0   (a=1.2: 偏在大, a→∞: 均一)
degree_factor = (degree / mean_degree) ^ power
shares = base_shares × degree_factor   (正規化)
```
ハブ企業（BA グラフで高次数）ほど大企業になる設計。

### market_stress ベース GARCH (Rounds 1-4)
```
base_var = σ²_mkt × (1 + stress_scale × market_stress + down_scale × downside_stress)
market_var = (1-α-β) × base_var + α × c²_{t-1} + β × market_var + leverage
```

### 実現ボラ 外部注入方式 (Round 5)
```
base_var[t] = rolling_63day_var(SP500_real_returns, t)   # フィードバックなし
market_var = (1-α-β) × base_var + α × c²_{t-1} + β × market_var + leverage
```
EWMA 方式 (Round 4) は t₅ 分布の E[z²]=5/3 により有効持続性 α×5/3+β=1.037>1 となり発散していた。

## 主な知見

### 1. 時価総額の偏在化の効果は限定的

Pareto (a=1.2) + 次数相関 (power=0.7) を加えても absacf5 は 0.077→0.075 とほぼ不変。

**理由**: price_impact × imbalance ≈ 0.0008 に対し common_noise + idio_noise ≈ 0.01 (SNR ≈ 0.08)。
時価総額の偏在によるインデックス集中が imbalance の INDEX への効果を増幅するが、
SNR が低すぎて自己相関への寄与は小さい。

### 2. price_impact 強化が最も効果的

price_impact を 0.008→0.018 に引き上げると absacf5 が 0.077→0.093 (+21%)。
Pareto 分布と組み合わせても、さらなる改善効果は見られない（0.088 < 0.093）。

### 3. market_stress の変動が自己相関の源泉

GARCH stable (stress_scale=2.0) や実現ボラ方式（固定 base_var）では absacf5 が 0.05-0.06 と悪化。
market_stress によって base_var が時変することが、有効な GARCH 持続性を生む。

### 4. 実現ボラ EWMA 方式の設計上の問題

EWMA(common_noise²) を omega にフィードバックする場合:
- common_noise ~ t₅(0, √V) → E[c²] = (5/3)×V
- GARCH 定常条件: α×(5/3) + β < 1 → 0.07×1.67 + 0.92 = 1.037 > 1
- → 技術的には発散 (cap に当たり続ける)

外部注入方式 (rolling 63日) は安定だが、base_var の変動が減り autocorrelation も低下。

| 課題 | 現状 | 実データ |

**次の改善候補 (優先度順)**:
1. **投資家の資産規模の不均一化**: 大口投資家が市場を支配 → LLN がさらに崩れ, 時差反応が増幅
2. **グラフ構造の極端化 (variant_M)**: スケールフリー度を上げてハブ投資家の影響力を増す
3. **セクター専門化の強化**: 非専門家に誤った sector 信号を与える（現在は 0 信号）
