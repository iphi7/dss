# O系検証レポート: Kalmanなし belief-state SSM

## 目的

各投資家が企業ごとの多次元 belief state を持ち、Kalman filter なしで SSM 的に更新する場合に、グラフ構造の影響が強まるかを確認した。

N19 では毎期

$$
\hat{x}^{(i)}_t = g_i(y_t, W_i)
$$

として即時計算していた。O 系では

$$
\hat{X}^{(i)}_t
= F_i(\hat{X}^{(i)}_{t-1}, y_t, W_i)
$$

となり、投資家の内部推定が時刻をまたいで蓄積する。

## 解釈

### 1. belief-state SSM にするとグラフ差はかなり出る

O0/O1/O2 を比較すると、N19 よりグラフ条件の差が大きくなった。

- O0 partial graph: std 0.0191, absacf1 0.277, absacf5 0.255
- O1 zero graph: std 0.0121, absacf1 0.099, absacf5 0.103
- O2 perfect graph: std 0.0126, absacf1 0.102, absacf5 0.063

これは、投資家ごとの belief state が時間方向に蓄積することで、主観グラフの違いが消えにくくなったためと考えられる。

特に partial graph が zero/perfect より大きなボラ持続性を持つ点が重要である。完全グラフでは全投資家の推定が揃いやすく、逆に欠損・誤認を含む partial graph の方が投資家間の非同期性・異質性を作っている可能性がある。

### 2. ただし O0 は強すぎる

O0 は

$$
|r|\mathrm{ACF}_1 = 0.277,
\qquad
|r|\mathrm{ACF}_5 = 0.255
$$

で、実データよりも強い。さらに std も 0.0191 と高すぎる。一方で kurtosis は 2.65 と低く、裾の厚さは失われている。

つまり O0 は「持続的に大きく動きすぎるが、ジャンプ的な厚い裾は弱い」モデルになっている。

### 3. 改善候補は O10

価格インパクトを落とし、外生共通ノイズも少し弱めた O10 は比較的バランスがよい。

- std: 0.0115（実データ 0.0107 に近い）
- absacf1: 0.143
- absacf5: 0.114

ただし kurtosis は 2.69 と低く、leverage も正である。

### 4. グラフ寄与の観点では O は前進

N19 では zero/perfect/partial graph の差が小さかったが、O 系では差が明確に出た。これは、投資家が内部状態を持つことにより、主観グラフの違いが毎期リセットされず蓄積したためである。

## 残る課題

- kurtosis が低すぎる。厚い裾を別途戻す必要がある。
- O0 はボラ持続が強すぎるため、価格インパクトや alpha を調整する必要がある。
- perfect graph が partial graph より弱いのは興味深いが、解釈には追加診断が必要。
- leverage effect はまだ再現できていない。
- DGS10 との相関も実データと逆符号のまま。

## 結論

Kalman filter なしでも、投資家が belief state を持つ SSM にすると、グラフ構造の影響は明確に強まった。

したがって、元の構想である

> 投資家ごとに企業状態推定を持ち、主観グラフに基づいて SSM 的に更新する

という方向は有望である。

ただし、N19 で得られていた尖度やバランスは失われたため、今後は O10 を土台にして、厚い裾を戻す機構を追加するのがよい。

## 追加検証: 外生ジャンプと流動性クラッシュ

ユーザ指摘に基づき、尖度不足の原因候補として以下の2つを検証した。

1. **稀な外生ショックを戻す**：`c_t` は市場活動依存には戻さず、外生ジャンプ頻度・サイズだけを増やす。
2. **流動性クラッシュ**：取引量 fast/slow 比率が閾値を超えた時だけ、価格インパクトを非線形に増幅する。

流動性クラッシュは以下で実装した。

$$
\lambda_t
= \lambda_0 \cdot \mathrm{clip}\left(
1 + a(
u_t-1)_+ + b(
u_t - 
u_c)_+^p \right)
$$

ここで

$$

u_t = \frac{V^{fast}_{t-1}}{V^{slow}_{t-1}}
$$

である。重要なのは、この追加項は `c_t` ではなく注文インパクトに入る点である。

### 解釈

- 外生ジャンプだけでも kurtosis は上がる。O10 の 2.69 から、O13 では 4.34 まで改善した。
- 流動性クラッシュだけでも ACF と kurtosis が改善する。O15 では absacf1=0.171, absacf5=0.146 となり、ボラクラ指標はかなり良い。
- 外生ジャンプ + 流動性クラッシュを組み合わせると、kurtosis はさらに上がる。
- O20 は kurtosis=9.08 と実データ 10.10 に近いが、absacf は弱くなる。
- O19 は kurtosis=7.47、absacf1=0.163、absacf5=0.145 で、尖度とボラクラのバランスは比較的良い。

### 結論

尖度が低かった主因の一つは、やはり `c_t` の外生ジャンプ成分を弱めすぎたことだった。ただし、外生ジャンプだけでなく、流動性クラッシュも尖度とボラクラの改善に効く。

現時点の候補は以下。

- **O17**: ボラクラ重視。absacf1/5 が良い。
- **O19**: バランス重視。ACF と kurtosis の両方がそこそこ良い。
- **O20**: 尖度重視。kurtosis は実データに近いが ACF は弱め。

次に使うなら、私は **O19** を土台にするのがよいと思う。O19 は `c_t` を市場活動依存に戻さず、外生ジャンプと流動性クラッシュだけで厚い裾をある程度戻しているため、設計思想とも整合的である。

### O 系の主な発見

1. **グラフ寄与が初めて明確に出た**: N 系では zero/partial/perfect の差が小さかったが、O 系では O0(partial) absacf5=0.255 vs O1(zero) 0.103 と明確な差が出た。belief-state の時間蓄積により、主観グラフの違いがリセットされずに持続するためと解釈できる。

2. **partial graph が perfect/zero より持続性が高い**: 完全グラフでは全投資家の推定が揃いすぎて異質性が失われる。不完全グラフの方が投資家間の非同期性・意見の食い違いを維持し、価格変動の持続性に貢献する。

3. **流動性クラッシュが有効な非線形増幅器**: O15（流動性クラッシュ単独）で absacf5=0.146 まで改善。外生ジャンプ + 流動性クラッシュの組み合わせ（O17-O19）でさらに改善。

4. **absacf1=0.163 で実データと一致**: O19 の absacf1 は実データ（0.1626）とほぼ一致する初めての結果。
