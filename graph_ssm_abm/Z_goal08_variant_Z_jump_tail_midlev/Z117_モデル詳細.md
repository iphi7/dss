# Z117 モデル詳細

グラフ構造をもつ企業ネットワークと異質な投資家エージェントのミクロな相互作用から、
SP500 と DGS10（米10年金利）の日次パスを60年分（14,882営業日）共生成するエージェント
ベースモデル。Z_goal08 系列の第30ラウンドまでの検証で確定した最終構成である。

- 生成対象: `sp500_abs`（指数水準）, `sp500`（日次リターン）, `DGS10_abs`（金利水準 %）, `DGS10`（金利日次変化 %ポイント）
- 外部入力: なし（初期値のみ。金利初期値 4.63% は1966年実データと同じ）
- 実装: `model.py`（Config）+ `model_gpu.py`（PyTorch, 60年1本 ≈ 55秒/Quadro RTX 5000）
- 代表パス: `results_gpu_round30/Z117_exo_sb045/seed_2/generated_paths.csv`

## 1. 記号の規約

| 記号 | 意味 | 値/次元 |
|---|---|---|
| $n$ | 企業数 | 80 |
| $N$ | 投資家数 | 60 |
| $D$ | 企業状態の次元数（公開6 + セクター8 + 非公開6） | 20 |
| $t$ | 日次時刻 | $1 \le t \le 14882$ |
| $j, k$ | 企業の添字 | |
| $i$ | 投資家の添字 | |
| $m$ | 状態次元の添字 | $1 \le m \le D$ |
| $W$ | 真の企業間影響グラフ（BAグラフ・行正規化） | $n \times n$ |
| $W_i$ | 投資家 $i$ の主観グラフ（辺の部分保持+偽辺+行正規化） | $n \times n$ |
| $x_{j,t,m}$ | 企業 $j$ の真の潜在状態 | |
| $b_{i,j,t,m}$ | 投資家 $i$ の企業 $j$ に対する信念状態 | |
| $r_{j,t}$ | 企業 $j$ の日次リターン | |
| $r_t$ | 指数（SP500相当）の日次リターン | |
| $y_t$ | DGS10 水準（%） | |
| $\Delta y_t$ | DGS10 の日次変化（%ポイント） | |
| $\hat{\sigma}_t$ | 指数リターンの実現ボラ（EWMA、減衰 0.95） | |
| $\sigma_0$ | 参加率・ストレスの基準ボラ `market_vol` | 0.0045 |

その他の記号は各節で定義する。$\mathcal{N}(a, b^2)$ は平均 $a$・分散 $b^2$ の正規分布、
$T_{\nu}$ は自由度 $\nu$ の t 分布乱数、$U(a,b)$ は一様分布、
$\mathrm{clip}(x, a, b) = \min(\max(x, a), b)$ とする。

## 2. 全体像 — 1日の処理フロー

```
t日目:
 (1) 企業の真の状態 x が遷移（AR(1) + ネットワーク伝播 + 稀な大ショック）
 (2) 公開・セクター次元の観測 y_obs が生成される（非公開次元は観測不可）
 (3) 各投資家が信念 b を更新（予測 + 観測とのブレンド；主観グラフ W_i を使用）
 (4) 売買スコア S を計算
       価値・トレンド・不確実性 + 金利水準ペナルティ
       + 金利レジーム項（κ_t × 前日の金利変化の外生成分）
 (5) 参加率を決定（ボラ感応 + ストレス記憶 + 日次ノイズ）
 (6) 確率的に売買 → 注文金額 → 資金制約 → 企業ごとの注文不均衡
 (7) 企業リターン r_j = 価格インパクト×不均衡 + 共通ショック + 個別ノイズ + アンカー
       共通ショックは「日常ノイズ×余震 + 中規模ジャンプ + 災害エピソード + メガクラッシュ」
 (8) 指数リターン r_t = 時価総額加重平均、指数水準を更新
 (9) 当日の金利変化 Δy_t を生成（持続ドリフト + 平均回帰 + 確率ショック
       + 株→金利チャネル κ_t × r_t）→ 金利水準を更新
(10) 内部状態を更新（実現ボラ、下落記憶、投資家ストレス、余震、危機強度、金利ドリフト等）
```

株→金利は同日（(9) が (8) の $r_t$ を見る）、金利→株は1日遅れ（(4) が前日の $\Delta y$ を見る）
の双方向結合である。

## 3. 構成要素の詳細

### 3.1 企業ネットワークと真の状態

企業 $j$ の潜在状態は $D=20$ 次元で、次元ごとに AR(1) + ネットワーク伝播に従う:

$$
x_{j,t,m} = \phi_m\, x_{j,t-1,m} + \rho_m \sum_{k=1}^{n} W_{jk}\, x_{k,t-1,m} + \eta_{j,t,m},
\qquad \eta_{j,t,m} \sim \mathcal{N}(0, \sigma_{\eta,m}^2)
$$

- $\phi_m \in [0.52, 0.88]$: 次元別の自己回帰係数（公開次元ほど持続的）
- $\rho_m \in [0.06, 0.35]$: ネットワーク伝播係数（非公開次元ほど強い）
- $\sigma_{\eta,m} \in [0.012, 0.026]$: 次元別ノイズ標準偏差
- 第1次元のみ、確率 0.004 で $T_{3} \times 0.28$ の稀な大ショックが加わる

$W$ は Barabási–Albert グラフ（接続数パラメータ 3）を行正規化したもの。企業は8セクターに
ランダムに属する。時価総額の初期シェアは Pareto 分布（形状 1.2）×次数べき（指数 0.7）で
少数の大企業が指数を支配する現実的な偏在を持つ。

### 3.2 観測

公開次元（$m \le 6$）はモメンタム付きで観測される:

$$
y^{\mathrm{obs}}_{j,t,m} = x_{j,t,m} + \mu_m \cdot s_{\mathrm{om}} \cdot (x_{j,t,m} - x_{j,t-1,m}) + \varepsilon^{\mathrm{pub}}_{j,t,m},
\qquad \varepsilon^{\mathrm{pub}}_{j,t,m} \sim \mathcal{N}(0, 0.04^2)
$$

$\mu_m$ は観測モメンタム係数（第1次元 0.35、他 0.15）、$s_{\mathrm{om}}$ = `obs_momentum_scale` = **0**。
すなわち Z117 では観測モメンタムは無効化されている（Round13 で、小さな正リターン後に
買い活動が増え低ボラ分位の leverage 相関を歪めるアーティファクト源と特定されたため）。

セクター次元（$7 \le m \le 14$）は $\varepsilon^{\mathrm{sec}} \sim \mathcal{N}(0, 0.05^2)$ で同様に観測される。
非公開次元（$m \ge 15$）は直接観測できず、観測済み次元の固定線形結合（アンカー）を
主観グラフ経由で擬似観測する。

### 3.3 投資家の信念更新

投資家 $i$ は主観グラフ $W_i$（真の辺を専門セクターで高確率・非専門で低確率に保持し、
少数の偽辺を加えて行正規化）を持ち、信念を予測と観測のブレンドで更新する:

$$
b^{\mathrm{pred}}_{i,j,t,m} = \phi^{b}_i\, b_{i,j,t-1,m} + \rho^{b}_{i,m} \sum_{k=1}^{n} (W_i)_{jk}\, b_{i,k,t-1,m}
$$

$$
b_{i,j,t,m} = (1 - \alpha_{i,j,m})\, b^{\mathrm{pred}}_{i,j,t,m} + \alpha_{i,j,m}\, y^{\mathrm{obs}}_{j,t,m}
$$

- $\phi^b_i \sim \mathcal{N}(0.72, 0.07^2)$ を [0.50, 0.90] にクリップ
- $\rho^b_{i,m}$: 公開/セクター次元では $\rho^b_{s,i} \sim \mathcal{N}(0.18, 0.06^2)$、非公開次元では $\rho^b_{h,i} \sim \mathcal{N}(0.28, 0.08^2)$
- 数値安定性のため $\phi^b_i + \rho^b_{\cdot,i} \le 0.97$ を保証（float32 では超えると60年で発散）
- $\alpha_{i,j,m} \in [0, 0.85]$: 更新率。専門セクターの企業で高く、非専門で低い

### 3.4 売買スコア

信念の次元加重和を現在推定 $\hat{e}_{i,j,t}$、1期先予測の加重和を $\hat{p}_{i,j,t}$ とし:

$$
S_{i,j,t} = v_i\, \hat{p}_{i,j,t} + \tau_i (\hat{p}_{i,j,t} - \hat{e}_{i,j,t}) - u_i \sqrt{R_i + Q_i} - g_i \frac{y_{t-1}}{100}
$$

- $v_i \sim \mathcal{N}(1.00, 0.25^2)$: 価値重視度、$\tau_i \sim \mathcal{N}(0.28, 0.12^2)$: トレンド重視度
- $u_i \sim U(0.15, 0.75)$: 不確実性回避度、$R_i, Q_i$: 観測・過程分散（対数正規）
- $g_i \sim U(0.02, 0.18)$: 金利感応度。$y_{t-1}$ は前日の生成金利水準（高金利ほどリスク資産のスコアが下がる）

次に投資家内センタリング（スコアから銘柄間平均の80%を差し引く。全銘柄共通のペナルティが
長期の一方的売り圧になるのを防ぐ）:

$$
S_{i,j,t} \leftarrow S_{i,j,t} - 0.8 \cdot \frac{1}{n}\sum_{k=1}^{n} S_{i,k,t}
$$

**金利レジーム項**（センタリングの後に加算。全銘柄共通の売買圧として機能させるため）:

$$
S_{i,j,t} \mathrel{+}= \beta_B \cdot \kappa_t \cdot \Delta y^{\mathrm{exo}}_{t-1} \cdot \frac{g_i}{0.10}
$$

- $\beta_B$ = `rate_change_score_beta` = **0.45**
- $\kappa_t$: レジーム係数（3.7節）。低金利期 +、高金利期 −
- $\Delta y^{\mathrm{exo}}_{t-1}$: **前日の金利変化の外生成分**（3.7節の株由来項を除いた部分）。
  金利変化全体に反応させると「株→金利（同日）→翌日スコア→株」の1日往復が生リターンに
  正の自己相関を合成するため（Round30 で確認、r_acf1 = +0.10 → −0.03 に修正）

### 3.5 参加率・注文・資金制約

**基本参加率**はボラ感応度 $v^{\sigma}_i$（正=リスク選好、負=リスク回避、$\mathcal{N}(0.65, 0.65^2)$ を [−2, 3] にクリップ）から:

$$
\pi_{i,t} = \mathrm{clip}\left( \left[ \mathrm{clip}\left(1 + v^{\sigma}_i \left( \frac{\hat{\sigma}_{t-1}}{\sigma_0} - 1 \right),\ 0.05,\ 2.2\right) \right]^{1.21},\ 0.10,\ 2.8 \right)
$$

上限（2.2 / 2.8）は「高ボラ→高参加→高ボラ」の自己維持ゲインの制御（Round3）。

**投資家別ストレス記憶**: 下落からのストレスを投資家ごとに異なる記憶長で保持する:

$$
q_{i,t} = \rho_{q,i}\, q_{i,t-1} + (1 - \rho_{q,i}) \cdot 1.4 \cdot \max(-r_{t-1}, 0)^2
$$

減衰率 $\rho_{q,i}$ は「リスク選好度×資産」の順位に応じて [0.90, 0.988] に線形配置
（大口のリスク選好投資家ほど記憶が長い。10日〜60日スケールの leverage の持続源）。
超過ストレス $\tilde{q}_{i,t} = \mathrm{clip}(q_{i,t}/\sigma_0^2,\ 0,\ 3.35)$ に対し:

$$
\pi_{i,t} \leftarrow \mathrm{clip}\left(\pi_{i,t}\, \frac{1 + 0.45\, \tilde{q}_{i,t} \max(v^{\sigma}_i, 0)}{1 + 0.29\, \tilde{q}_{i,t} \max(-v^{\sigma}_i, 0)},\ 0.05,\ 8.0\right)
$$

（リスク選好投資家はストレス下で参加増、リスク回避投資家は退避。）
さらに注文サイズにも $1 + 0.30\, \tilde{q}_{i,t} \max(v^{\sigma}_i, 0)$ の倍率がかかる。

**参加率の日次ノイズ**: $\pi_{i,t} \leftarrow \pi_{i,t} \cdot \exp(0.35\, \xi_{i,t})$、$\xi_{i,t} \sim \mathcal{N}(0,1)$。
平常時の滑らかなボラ持続が $|r|$ の lag1 自己相関を過剰にするのを希釈する（Round20）。

**売買の決定**: 買い/売りオッズ

$$
z^{\mathrm{buy}}_{i,j,t} = e^{\theta_i S_{i,j,t}}\, \pi_{i,t}, \qquad
z^{\mathrm{sell}}_{i,j,t} = e^{-\ell_i \theta_i S_{i,j,t}}\, \pi_{i,t}
$$

- $\theta_i \sim U(2, 6)$: 温度、$\ell_i \sim U(1.0, 1.9)$: 損失非対称度
- 前日リターンが −0.6% を下回ると全投資家の売りオッズに弱い恐怖倍率（スケール 0.0005、実質ほぼ無効）

確率 $z^{\mathrm{buy}}/(z^{\mathrm{buy}}+z^{\mathrm{sell}}+1)$ で買い、同様に売りを決定。注文金額は
資産×リスク許容度×確信度×対数正規ノイズで、買い合計は現金でスケール制約。
毎日、ポートフォリオ価値の 0.08% を市場ウェイトへ戻す turnover（60年での保有固定化防止）。

**投資家母集団の層化抽出**（`investor_stratified=True`）: 資産の対数とボラ感応度を
分位数グリッド $u_i = (i+0.5)/N$ から標準正規分位関数で生成し（ペアリング置換のみ乱数）、
母集団の抽出誤差を除去する。iid 抽出では $N=60$ のとき「大口リスク選好投資家（クジラ）」の
有無が乱数次第となり、市場が取引主導ボラへ発火するか否かが母集団ガチャで決まってしまう
（Round3 で seed1〜5 全てでクジラの有無と発火の一致を確認。Round4 で層化により全 seed 発火）。

### 3.6 価格形成

企業 $j$ の日次リターン:

$$
r_{j,t} = \lambda\, F_t\, I_{j,t} + c_t + \epsilon_{j,t} + A_t,
\qquad r_{j,t} \leftarrow \mathrm{clip}(r_{j,t},\ -0.24,\ 0.24)
$$

- $I_{j,t} = \dfrac{B_{j,t} - S^{\mathrm{ord}}_{j,t}}{B_{j,t} + S^{\mathrm{ord}}_{j,t} + 10^{-9}}$: 注文不均衡（$B$=買い金額、$S^{\mathrm{ord}}$=売り金額）
- $\lambda$ = `price_impact` = **0.019**: 基本価格インパクト
- $\epsilon_{j,t} = T_{5} \times$ 企業別ボラ（基準 0.008）: 個別ノイズ
- $A_t$: 指数水準アンカー（強さ 0.002 の弱い tanh 型平均回帰、年率 +6.3% の成長トレンド付き。
  60年での価格崩壊防止。強さ 0.006 から 0.002 へ弱めたのは低ボラ分位の leverage 歪み対策 — Round13-14）

**インパクト増幅係数** $F_t$:

$$
F_t = \mathrm{clip}\Big( \Lambda_t \big[ 1 + 0.9 \max(0, V_t - 1) \big] + 0.3 \max(0, V_t - 1.25)^{2},\ 0.25,\ 3.2 \Big)
$$

$V_t$ は取引金額の速い EWMA（減衰 0.94）/遅い EWMA（減衰 0.99）の比（活動比率）。

**非対称価格インパクト** $\Lambda_t$（leverage effect の主機構）:

$$
d_t = 0.75\, d_{t-1} + 0.25 \max(-r_{t-1}, 0)^2, \qquad
e_t = \max\left( \frac{d_t}{\hat{\sigma}^2_{t-1} / 2} - 0.25,\ 0 \right)
$$

$$
\Lambda_t = 1 + 1.6 \cdot 0.8 \tanh(e_t / 0.8)
$$

- $d_t$: 下落分散の記憶（減衰 0.75 — 反応を1週間強持続させ 7〜20日 horizon の leverage を作る）
- 活性化閾値 0.25（1.0 から引き下げ。中程度の下落でも活性化し中位分位の leverage を作る — Round8）
- tanh 飽和 0.8（極端な下落での過剰応答を抑え最上位分位の過剰を防ぐ — Round8）
- スケール 1.6（Round21 で 1.0 から増強。iid ノイズ再配分で弱まった leverage の回復）

### 3.7 共通ショックの階層構造

市場共通ショック $c_t$ は5層で構成される:

$$
c_t = \mathrm{clip}\Big( \zeta_t + J^{(2)}_t + J^{\mathrm{dis}}_t + J^{\mathrm{mega}}_t,\ -0.24,\ 0.24 \Big)
$$

**(a) 日常ノイズ × 余震**: $\zeta_t \sim \mathcal{N}(0,\ \sigma_{c,t}^2)$、

$$
\sigma_{c,t} = 0.0064 \times (1 + 35\, g^{(1)}_{t-1} + 5\, g^{(2)}_{t-1})
$$

$g^{(1)}, g^{(2)}$ は余震状態（下記 (e)）。基準値 0.0064 は Round20 の「iid ノイズ再配分」で決定
（0.00445 から増額。取引由来の持続成分を減らし iid 成分を増やすことで $|r|$ の自己相関を実データ形状にする）。

**(b) 中規模ジャンプ（第2層）**: 確率 0.012（年約3回）で $J^{(2)}_t = T_{5} \times 0.016 \times V^{\kappa}_t$。
$V^{\kappa}_t = \mathrm{clip}((\hat{\sigma}_{t-1}/\sigma_0)^{0.35}, 0.3, 3.0)$ はボラ連動係数
（静穏期の不自然な巨大ジャンプ=尖度爆発を抑える — Round6）。

**(c) 災害エピソード（複数日クラッシュ）**: 確率 0.0004（60年に約6回）で開始。強度 $I^{\mathrm{dis}}_t$ は
開始時 1.0、**8日間プラトー**（1.0 を維持）ののち日次 0.78 で幾何減衰、0.3 未満で終了。継続中は毎日

$$
J^{\mathrm{dis}}_t = \left( T_{8} \times 0.040 - 0.012 \right) \times I^{\mathrm{dis}}_t
$$

- 単日の特大ジャンプを複数日に分割した構造（実データの2008・2020型危機に対応）。
  連続する大きな日次ショックが二乗リターンの自己相関の源になる（Round11 で導入、iid 巨大
  ジャンプが $r^2$ 分散を支配して sq_acf を希釈する問題の構造的解決）
- プラトー 8日: 実データの sq_acf が lag5 まで平坦（危機ボラの1〜2週間の高止まり）に対応（Round18）
- 負の平均シフト −0.012/日: 危機週を net 下落にし（現実整合）、「大下落日→高ボラ持続」の連鎖で
  最上位分位の leverage を内生的に作る（Round19。外生対称ショックは leverage を希釈する）

**(d) メガクラッシュ**: 確率 6.7×10⁻⁵（60年に約1回）で単日

$$
J^{\mathrm{mega}}_t = -0.20 \times U(0.9, 1.1)
$$

1987年型の −20% 級・負符号固定の独立層（Round15。実データの Q-Q は「中規模がそこそこ +
特大がごく稀」の2階層構造を示す）。発生時は災害エピソードを強度 1.2 で誘発する
（1987年の暴落翌日以降の +5.3%/−8.3%/+9.1% の乱高下に対応。孤立した単日巨大 $r^2$ が
sq_acf を希釈するのを防ぐ — Round16）。

**(e) 余震状態**: 全ジャンプ（(b)(c)(d)）の絶対値合計 $a_t$ を2つの時定数で保持:

$$
g^{(1)}_t = 0.72\, g^{(1)}_{t-1} + a_t \quad (\text{数日スケール}), \qquad
g^{(2)}_t = 0.96\, g^{(2)}_{t-1} + a_t \quad (2\text{〜}3\text{週間スケール})
$$

第2成分は sq_acf の lag10〜20 の持続源（Round16）。

### 3.8 指数

$$
r_t = \sum_{j=1}^{n} w_{j,t}\, r_{j,t}, \qquad w_{j,t} = \frac{\text{時価総額}_{j,t}}{\sum_k \text{時価総額}_{k,t}}
$$

指数水準は $\mathrm{SP}_t = \mathrm{SP}_{t-1}(1 + r_t)$。

### 3.9 DGS10 の生成と株との双方向結合

**レジーム係数**（金利環境に応じて株-金利相関の符号を切り替える）:

$$
\kappa_t = \tanh\left( \frac{5.5 - \tilde{y}_t}{1.5} \right), \qquad
\tilde{y}_t = y_{t-1} + 2.5 \cdot \max(y_{t-1} - y_{t-251},\ 0)
$$

- 中心 5.5%: 高金利（κ<0、割引率チャネル: 金利上昇→株安）と低金利（κ>0、リスクオン:
  好況→株高&金利上昇、リスクオフ→株安&国債買い）の境界。tanh の飽和の非対称を補正して
  実データの負時代（平均 −0.32）と正時代（+0.35）を対称に出すため 4.5 から引き上げ（Round25）
- トレンド補正 2.5: 「水準が低くても金利が1年前より急上昇中（インフレ局面）は割引率チャネル側へ」。
  実データの 2022-23（水準4%台で相関ゼロ〜負）と 1966-69（低水準・上昇中・負相関）に対応（Round25-26）

**金利の日次変化**（株の取引後に生成）:

$$
\Delta y_t = d^{\mathrm{rate}}_t + 0.00025\,(5.5 - y_{t-1}) + \sigma^{\mathrm{rate}}_t\, T_{4.5} + 2.5\, \kappa_t\, r_t
$$

各項:

1. **持続ドリフト**（インフレレジーム）: $d^{\mathrm{rate}}_t = 0.9995\, d^{\mathrm{rate}}_{t-1} + \varepsilon^{\mathrm{rate}}_t$、
   $\varepsilon^{\mathrm{rate}}_t \sim \mathcal{N}(0, (8 \times 10^{-5})^2)$。記憶約8年の AR(1) が実データの
   数十年スケールの大波（1966→81 上昇 / 81→2020 下降）を作る
2. **弱い平均回帰**: 速度 0.00025（Round28 で 2×10⁻⁵ から増強。上限への張り付き解消）、中心 5.5%
3. **確率ショック**: $\sigma^{\mathrm{rate}}_t = 0.024 \times (y_{t-1}/5)^{0.35} \times \sqrt{\mathrm{clip}(h_t, 0.3, 4)}$、
   $h_t = 0.95\, h_{t-1} + 0.05\, T_{4.5,t-1}^2$。水準依存ボラ（べき 0.35 は実データ推定値）×
   分散クラスタ×自由度 4.5 の t 分布（実データの変化尖度 8.4 に対応）
4. **株→金利チャネル**: 係数 2.5。当日の株リターンにレジーム係数を掛けて加算。
   リスクオン期は株安→金利低下（質への逃避）。**同日の株金利相関の主たる源**

変化を ±0.9pp（実データの最大 |Δ|=0.75pp に対応）、水準を [0.4%, 16%] でクリップして
$y_t = y_{t-1} + \Delta y_t$。

**外生成分の分離**: スコアの金利レジーム項（3.4節）が参照するのは

$$
\Delta y^{\mathrm{exo}}_t = \Delta y_t - 2.5\, \kappa_t\, r_t
$$

（項1+2+3のみ）。金利変化全体に反応させると株→金利→翌日スコア→株の1日往復が
$\kappa^2 > 0$ により常に正のリターン自己相関を合成するため（Round30）。

## 6. 既知の限界・残課題

1. **相関の正側の振れが強い**（q95 +0.80 vs 実 +0.58）— 株→金利結合の非対称化が候補
2. **|r| acf5 と r² acf5 が実データより速く減衰**（中期ボラ持続の選択的な追加が必要）
3. **中位分位（5-8）の leverage が約6割**（−0.066 vs −0.109）
4. **金利の |変化| クラスタ不足**（0.13 vs 0.25）— 金利側の余震機構が候補
5. 尖度・std の seed 間ばらつき（金利の大波の形に依存）
