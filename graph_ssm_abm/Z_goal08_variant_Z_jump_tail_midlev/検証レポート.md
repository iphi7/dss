# Z_goal08_variant_Z_jump_tail_midlev 検証レポート

## 目的

Y_goal07 の引き継ぎ課題（ユーザー指摘）3点を改善する。

1. **Y14/Y15 の中間**: volatility clustering を Y14 程度に保ちつつ短期 decile10 leverage を抑える
2. **中位分位（5-9分位）leverage の回復**: Y15 では実データ（5d で −0.07〜−0.13）に対しほぼ 0 に消失
3. **ジャンプサイズの回復**: 絶対リターン Q-Q プロットの裾が実データに届かない

評価は全 Round で seed 1/2/3 の3サンプル、60年パス（14,882日）、multi-lag ACF・分位別 leverage・裾分位点を含む拡張スコアで行った。

## 検証の経緯（Round1〜7）

### Round1: 機構分離 — 2つの重要発見

Z01（Y14/Y15単純中間）〜Z07（複合）で機構を1つずつ検証した。

**発見1: ジャンプサイズ不足の直接原因は `firm_return_clip=0.08`**。
Y15 の max|r| はちょうど 0.0800 でクリップに張り付いていた（`exog_common_clip` を 0.16 に広げても企業リターン側のクリップが束縛）。0.20 への解放で max|r|=0.080 → 0.195（実データ 0.205）に回復。

**発見2: seed1/seed3 が「低ボラ・トラップ」に崩壊**。
std≈0.006 の死んだ状態に大ジャンプが乗り、kurtosis が 240〜310 に爆発。健全な動態は seed2 のみだった。

### Round2: トラップ解消の試み → 双安定レジーム構造の診断

基準ボラ引き下げ（market_vol 0.006→0.0045）・参加率フロアのいずれもトラップを解消できなかった。ローリング std の診断により以下が判明:

- 系は「死」（rolling std≈0.005）と「高温」（≈0.019）の**双安定**
- seed2 も最初の10年は死んでおり、12年目頃に発火して以後高温に定着
- **実データも rolling std 0.0054〜0.0215 のレジームを持つ**（60s-70s 静穏、87-88・2008 高ボラ）。問題は双安定ではなく「遷移が起きない/一方向」なこと

### Round3: 遷移制御の試み → 無効 → クジラ仮説の確認

実現ボラ EWMA の高速化（λ=0.95）や参加率上限の削減は遷移構造をほぼ変えなかった。発火が vol_factor 経路で決まっていないことを示唆。

投資家母集団を診断した結果、**発火の決定要因は「大口リスク選好投資家（クジラ）」の有無**と判明:

| seed | クジラ実効パワー* | 発火 |
|---|---:|---|
| 1 | 0.72 | ✗ |
| 2 | 1.38 | ✓（12年目） |
| 3 | 0.72 | ✗ |
| 4 | 0.59 | ✗（追試で確認） |
| 5 | 1.50 | ✓（追試で確認） |

*実効パワー = wealth × max(vol_sensitivity, 0) × risk_tolerance の個人最大値

5 seed 全てでクジラの有無と発火が一致。**市場のレジーム構造（発火するか否か）が投資家母集団の抽出運（ガチャ）で決まっていた。**

### Round4: 層化抽出 — ブレイクスルー

`investor_stratified=True`: wealth と vol_sensitivity を分位数グリッドから生成（ペアリング置換のみ乱数）し、母集団の抽出誤差を除去。

- **seed3 が発火するようになった**（std 0.0116、abs_acf5=0.287）
- score 平均 0.50 前後 → **0.396** へ大幅改善
- 対照実験: corr 増強（Z19）や n_investors=100（Z20）は逆効果

### Round5: 個別改善素子の検証

- stress=1.4（Z24）: seed2 の mid_5d=−0.095 と中位分位が目標 −0.109 に接近
- 投資家別ストレス記憶（Z25）: seed3 の ACF/kurt が改善
- jump tail 増強（Z26）: q999=0.082 と目標 0.070 を超過達成（統合時は弱める）
- 未解決: seed1 の部分発火。静穏期の大ジャンプで kurt 78〜89

### Round6: 統合 + ジャンプのボラ連動

有効素子を統合（Z27〜Z30）し、新機構 `jump_vol_coupling` を導入:

$$
J_t \leftarrow J_t \cdot \mathrm{clip}\left( (\hat{\sigma}_{t-1} / \sigma_0)^{c_v},\ 0.3,\ 3.0 \right)
$$

（$J_t$ = ジャンプ振幅、$\hat{\sigma}_{t-1}$ = 実現ボラ EWMA、$\sigma_0$ = 基準ボラ、$c_v$ = 連動指数）

静穏期の不自然な巨大ジャンプ（尖度爆発の源）を抑え、活発期の tail を保つ。実市場のクラッシュが活発な市場で起きることに対応する。

- Z30（統合 + vc=0.5 + vs_mean=0.65）: score 0.376、**3 seed 全てが発火**（seed1 も std=0.0106 まで回復）
- 副作用: ボラ連動で高温期のジャンプが増幅され q999=0.094 と過剰に

### Round7: tail の最終調整

jump_sigma 0.115 → 0.085 で q999 を目標に合わせた。

## 副次的成果（当初想定外の発見）

1. **firm_return_clip=0.08 の束縛**: Y系の「ジャンプを大きくしても裾が伸びない」原因はモデル側のクリップだった。
2. **レジーム双安定と発火のクジラ依存**: seed 依存問題（引き継ぎメモ §8）の根本原因を特定。「seed1 が低ボラ・高尖度になる」のは乱数の運ではなく、**投資家母集団に大口リスク選好投資家が引かれるか否か**で決まっていた。
3. **層化抽出**: 母集団の抽出誤差を除去し、全 seed で発火を安定化。モデルの「投資家異質性の構造」は保ちながら、n=60 の有限抽出ノイズだけを除去する設計。
4. **ジャンプのボラ連動**: 静穏期の尖度爆発を抑える一般的な機構として他系列にも移植可能。

## Round8〜10: ユーザーフィードバック対応

Z32 に対する指摘: ①sq_acf が不自然に低い（R03 では 0.24 あった）、②分位9 の leverage が 1d〜7d で約 0.1 過剰、③ジャンプは「中規模がそこそこ + 特大がごく稀」の2層構造にすべき。

### 診断

- **sq_acf 低下の原因**: クリップ解放後の巨大ジャンプが iid で入り、$r^2$ の分散を単発の外れ値が支配して相関を薄めていた。R03/Y14 で sq_acf が高かったのは `firm_return_clip=0.08` がジャンプを切っていたことの裏返し。
- **分位9 過剰の原因**: `asym_pi` の反応が高分位に集中しすぎ（threshold=0.55 でも大きな下落でしか活性化しない）かつ短命（down_ewma_decay=0.60）。Z32 の分位9 は 1d=−0.165（実 −0.089）で、7d 以降は逆に弱かった。

### 対応（Round8: Z33〜Z36）

**2層ジャンプ**（`exog_common_jump2_*` を新設）:

- 第1層 = 特大・超レア: 確率 0.0004〜0.0006（10年に1〜1.5回）、スケール 0.12〜0.13、自由度 2.5
- 第2層 = 中規模・年数回: 確率 0.012（年約3回）、スケール 0.020、自由度 5

両層とも余震状態に加算されるため、中規模ジャンプ→数日の高ボラという $r^2$ クラスタが繰り返し発生し、sq_acf の回復源になる。

**asym_pi 再形状化**: threshold 0.55→0.25（中程度の下落でも活性化 → 分位5-8 を持ち上げ）、sat 1.3→0.8（強い飽和 → 分位9/10 の 1d 過剰を圧縮）、down_ewma_decay 0.60→0.75（反応を持続させ 7d 以降を強化）。

Round8 で sq_acf は回復（Z35 seed1: 0.252）したが、std・q999 が過剰化し dec10 が希釈。Round9 でジャンプ規模を縮小し vol_coupling を 0.35 に弱めて Z38（score 0.356）が新最良。Round10 で asym_pi_scale 1.0 と特大ジャンプ増強・余震強化を加えた。

## Round11〜14: 構造的修正（災害エピソード・低分位正相関の原因特定）

Z43 への追加指摘（①分位3-4の正相関、②abs強/sq弱の不均衡、③超特大ジャンプ過多）に対し、
パラメータ調整でなく構造変更で対応した。

### 災害エピソード（複数日クラッシュ）— ②③の構造的解決

単日の特大ジャンプを廃し、「数日間続く危機エピソード」に置き換えた（`disaster_*`）。
トリガー日に強度 1.0 で開始し、毎日

$$
\Delta c_t = T_{\nu_d} \cdot \sigma_d \cdot I_t, \qquad I_{t+1} = \rho_d I_t
$$

（$T_{\nu_d}$ = 自由度 $\nu_d$ のt分布乱数、$\sigma_d$ = 日次スケール、$I_t$ = エピソード強度、$\rho_d$ = 日次減衰率）を共通ノイズに加算し、強度が閾値未満で終了する。実データの危機（2008・2020）は −5〜−9% の日が連続する形で、単日 −20% は 1987 の1回のみ、という観察に対応する。

**効果**: 連続する大きな \|r\| が $r^2$ クラスタを作り、sq_acf5 が 0.08 → 0.17〜0.27 へ回復。
同時に >10% の単日が 12日 → 2〜7日（実データ 3日）へ正常化。

### デッドバンドの失敗（記録）

分位3-4 正相関への当初仮説「微小下落だけが記憶される非対称」に基づき、下落記憶に
デッドバンド（絶対値・相対値の2形）を試したが、**いずれも発火機構と両立しない**ことを確認
（Round11-12）。静穏レジームでは通常サイズの下落がストレス蓄積＝発火の燃料であり、
これを遮断すると市場が死んだまま になる。`down_deadband` / `down_deadband_rel` は非推奨として残置。

### 低分位正相関の真の原因 — 上昇側チャネル（Round13 切り分け）

正相関 =「小さい**正**リターンの後にボラが上がる」なので原因は上昇側にあると仮説を転換し、
4つのチャネルを1つずつ切って診断した:

| 腕 | 切ったチャネル | dec3_5d の変化 |
|---|---|---:|
| Z50（基準） | — | +0.001 |
| Z52 | 観測 momentum | −0.014 |
| **Z53** | **市場アンカー** | **−0.021** |
| Z54 | 全員一律 fear | +0.002（無関係） |
| Z55 | リスク回避退避強化 | +0.006（無関係） |

**主犯は市場アンカーと観測 momentum の複合**: 小さい正リターン → 価格がアンカー上へ →
引き戻し圧、および momentum で観測が強気化 → 買い活動増 → 取引・変動増。
ただしアンカー完全除去は年率リターンが負に流れる（seed3: −4.8%/年）ため、
**momentum 除去（`obs_momentum_scale=0`）+ アンカー弱体化（0.006→0.002）**で統合（Round14）。

## Round24〜29: DGS10 との相関 → DGS10 の内生生成

### 実データの構造（Round24 前の分析）

90日ローリング相関 corr(株リターン, 金利変化) は単一値ではなくレジーム構造を持つ:
1966-97 は一貫して負（−0.2〜−0.4、割引率チャネル）、2000-19 は一貫して正（+0.2〜+0.5、リスクオン）、2020s はゼロ近傍（インフレ再燃）。相関自体の lag250 自己相関 0.70 と年単位で持続し、分布は q05=−0.57 / q95=+0.58。**固定の rate_sensitivity では符号反転を原理的に再現できない**。

### レジーム係数 κ（Round24〜26、実データ金利で確立）

$$
\kappa_t = \tanh\left( \frac{c - \tilde{y}_t}{w} \right), \qquad
\tilde{y}_t = y_{t-1} + s \cdot \max(y_{t-1} - y_{t-251},\ 0)
$$

（$y$ = DGS10水準、$c$=5.5%、$w$=1.5%、$s$=2.5）。高金利で κ<0（割引率チャネル）、低金利で κ>0（リスクオン）。トレンド項 $s$ は「低水準でも金利急上昇中（2022-23、1966-69）は負相関側へ」を表す。

伝達経路は**投資家スコア経由**を採用（価格直接は leverage を希釈するため棄却）:
$$
S_{i,j,t} \mathrel{+}= \beta_B \cdot \kappa_t \cdot \Delta y_{t-1} \cdot (g_i / 0.10)
$$
score_centering の後に加算（全銘柄共通項が centering で消えないように）。実データ金利での確認: 時代別相関 era1/era2/era3 = −0.358/+0.316/−0.013（実 −0.316/+0.352/−0.021、Z103）。

### DGS10 の内生生成（Round27〜29）

ユーザー要件により、DGS10 を実データ入力から**相互作用型の内生生成**へ変更。1966年初期値（4.63%）から出発し、株価と双方向に結合しながら日次で逐次生成する:

$$
\Delta y_t = d_t + \theta (c_{\mathrm{mr}} - y_{t-1}) + \sigma_t T_{\nu,t} + \beta_{sr}\, \kappa_t\, r_t
$$

- $d_t = \rho_d d_{t-1} + \varepsilon_t$: 持続ドリフト（$\rho_d$=0.9995、インフレレジーム。数十年の大波の源）
- $\theta (c_{\mathrm{mr}} - y)$: 弱い平均回帰（$\theta$=2.5e-4、境界張り付き防止）
- $\sigma_t = \sigma_0 (y_{t-1}/5)^{\gamma} \sqrt{h_t}$、$h_t = \lambda h_{t-1} + (1-\lambda) T_{\nu,t-1}^2$: 水準依存ボラ（$\gamma$=0.35）×ボラクラスタ、$T_{\nu}$ は自由度 $\nu$ の t 分布（ファットテール）
- $\beta_{sr} \kappa_t r_t$: **株→金利チャネル**（$r_t$ = 当日株リターン）。リスクオン期は株安→金利低下（質への逃避）。同日相関の主たる源
- 反射境界 [0.4%, 16%]、日次変化クリップ ±0.9pp

**処理順**: 投資家は前日までの生成金利を見て取引（金利→株、1日遅れ）→ 当日の株リターン確定 → 当日の金利変化を生成（株→金利、同日）。

### 校正の経緯

- Round27: 相関分布は再現（Z106: q05/q50/q95 = −0.58/−0.13/+0.64）。ただし金利変化 std が実の1.4倍 → スコア経路経由で**株側が劣化**（sq_acf1 0.36、dec10 −0.26 と過剰）
- Round28: 金利σ校正（0.036→0.024）+ 平均回帰強化で張り付き解消。株側大幅回復
- Round29: スコアβ 0.9→0.55 + 金利 df 4.5/λ0.95 で最終校正。「金利ボラクラスタがスコア共通項経由で株の sq_acf に輸入される」効果を適正化

### Round30: 生リターン lag1 自己相関の修正（ユーザー指摘）

Z113 の r_acf1 = 0.075〜0.126（実 −0.015）と過剰に正だった。

**機序**: 相互作用ループ自体がモメンタムを合成していた。
$$
r_t \uparrow \;\to\; \Delta y_t \ni \beta_{sr}\kappa_t r_t \;(\text{同日}) \;\to\; \text{翌日スコア} \ni \beta_B \kappa_{t+1} \Delta y_t \;\to\; r_{t+1} \uparrow
$$
$\kappa^2 > 0$ なのでレジームによらず常に正方向（実データ金利では $\Delta y$ が $r$ と独立なため発生しなかった）。

**修正**（`rate_score_use_exo`）: 投資家スコアの金利変化項を、$\Delta y$ から株由来項を除いた**外生成分**に限定。「昨日の自分たちの売買が動かした金利には二重反応しない」という自然な仮定で、同日相関（株→金利チャネル）は保たれる。

結果: r_acf1 = **−0.025**（Z117、実 −0.015）に正常化。副次効果として sq_acf1 も 0.34→0.29 と改善（ループ由来の持続が消えた分）。
