# J_variant_J_scale

## 概要

スケールパラメータのアブレーション。`B_base1_H_variant_H_pub_priv` のモデルを使い、以下の3つを1つずつ変化させてスタイライズドファクトへの影響を検証する。

| パラメータ | ベース | 変化範囲 | 意味 |
|---|---|---|---|
| `n_firms` | 80 | 40 / 160 | 市場の企業数 |
| `n_investors` | 60 | 30 / 120 | 投資家数（大数の法則による平均化の強さ） |
| `ba_m` | 3 | 2 / 5 | BA グラフのハブ密度（m が大きいほどハブが強い） |

詳細は [検証レポート.md](検証レポート.md) を参照。
