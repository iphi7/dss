# E_variant_E_perfect_graph

## 概要

アブレーション: **全投資家の主観グラフを真の企業ネットワーク $W$ に完全一致させた場合**のスタイライズドファクトを、通常の主観グラフ（欠損・誤認あり）と比較する。

## 検証の動機

base モデルでは投資家ごとに異なる主観グラフ $W_i$（エッジ保持率 15〜55%、専門セクターにボーナス）を生成している。この多様性がスタイライズドファクトに寄与しているかを確認する。

## 実装

`model.py` に `Config.perfect_graph: bool` フラグを追加。

```python
if config.perfect_graph:
    subjective_graphs = np.tile(true_w[np.newaxis, :, :], (n_investors, 1, 1))
```

## 結果

| 指標 | real_tail | base | perfect_graph |
|---|---:|---:|---:|
| std | 0.01065 | 0.01353 | 0.01354 |
| kurtosis | 10.10 | 6.43 | 6.43 |
| \|r\| ACF lag-1 | 0.163 | 0.060 | 0.060 |
| leverage | -0.043 | +0.000 | +0.000 |

→ **全指標でほぼ完全に一致。主観グラフの多様性はスタイライズドファクトに影響しない。**

## 解釈

カルマンゲインが大きく（$K \approx 0.6 \sim 0.8$）、更新後の推定値が毎日ほぼ観測値 $y$ にリセットされるため、グラフの違いが伝播する前に修正される。また取引スコアが将来予測ではなく現在の推定値ベースになっているため、グラフ $W_i$ の差異が取引行動に反映されない。
