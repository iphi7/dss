# U_goal03_variant_U_ultrarare_graph_jumps

R03をベースに、グラフに応じてある程度連動するジャンプが「ごく稀に」起きる機構を検証したディレクトリです。

## 目的

これまでのS/T系ではジャンプの頻度が高めで、分布全体やQ-Q plotを動かしすぎる傾向がありました。
今回は発生頻度を60年で数回程度まで落とし、R03の良い通常時構造をなるべく維持したまま、最大級ジャンプだけを補えるかを確認します。

## 機構

イベント発生日に、企業グラフ上のショック源を選びます。

$$
P(j \in S_t) \propto (\deg(j)+\epsilon)^\alpha.
$$

ショック源ベクトルをグラフ上で伝播させます。

$$
\beta_t = z_t + \lambda Wz_t + \lambda^2 W^2z_t + \cdots.
$$

企業別リターンには

$$
r_{j,t} = r_{j,t}^{R03} + \beta_{j,t}J_t
$$

を追加します。

イベント発生確率は `0.00025〜0.00035` 程度で、約15000営業日あたり期待3〜5回程度です。

## 試した候補

- `U01_ultra_rare_local`: 局所的な超低頻度グラフジャンプ。
- `U02_rare_diffuse`: やや拡散的なグラフジャンプ。
- `U03_ultra_rare_neg`: 負方向イベントを強めた候補。
- `U04_rare_mixed_sign`: 企業ごとに符号を少しばらす候補。

## 評価

`U01 seed2` がR03に対して最も自然な小改良です。

- `abs_acf5` はR03とほぼ同等。
- `q999` は `0.0618 → 0.0680` に改善。
- maxは `0.0749 → 0.1259` に改善。
- raw return ACFは悪化していない。

ただし、`sq_acf5` は `0.238 → 0.185` に下がります。
また、q95/q99も少し動くため、完全に「最大級だけ」ではありません。

総合的には、依然としてR03の完成度が高いです。
U01は「R03にごく稀なグラフ連動ジャンプを足すならこの程度」という参考候補です。
