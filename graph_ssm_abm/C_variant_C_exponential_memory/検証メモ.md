# Variant C: 企業・投資家の指数減衰メモリ

## 追加した機構

企業側に、過去の潜在状態ショックを指数減衰で蓄積するメモリを追加した。

$$
u_{j,t}
=
\lambda_u u_{j,t-1}
+
(1-\lambda_u)
\left(
a_x |x_{j,t}|
+ a_{\Delta} |\Delta x_{j,t}|
+ a_{\eta} |\eta_{j,t}|
\right)
$$

投資家側には、予測誤差と推定分散からなる主観的不確実性メモリを追加した。

$$
u^{(i)}_{j,t}
=
\lambda_i u^{(i)}_{j,t-1}
+
(1-\lambda_i)
\left(
b_1 |y_{j,t}-\hat{x}^{(i)-}_{j,t}|
+ b_2 \sqrt{P^{(i)}_{j,t}}
\right)
$$

企業メモリは観測ノイズ・価格インパクト・個別ボラへ、投資家メモリは注文量へ反映した。

## 所感

単純にメモリを観測ノイズ・価格インパクト・注文量へ入れるだけでは、ボラティリティクラスタリングはほとんど改善しなかった。  
理由は、メモリが「当日の市場反応」には効く一方で、次期以降の企業潜在ショックそのものには十分戻っていなかったためと考えられる。

そのため、C2では企業メモリを次期の潜在ショック分散にも反映し、さらに企業ネットワーク上でメモリを伝播させた。
