# I系検証レポート: 部分観測（投資ユニバース限定）のアブレーション

## 目的

各投資家の観測対象を投資ユニバース $O_i$（専門セクター企業 + グラフ上の重要上位企業、計約20社）に限定し、ハブショック時に「反応の時差」が生まれるかを検証する。

## 設計

### 投資ユニバース $O_i$ の定義

```
O_i = 専門セクターの全企業（~10社）
    ∪ 主観グラフ W_i でスコアが高い上位企業（計20社になるよう補填）
```

$O_i$ 外の企業の観測値 $y_j$ は、最後に観測したときの値のまま更新されない（**陳腐化した情報**）。

```python
y_i[j] = y_full[j]    if j ∈ O_i    # 今期の観測
y_i[j] = y_i_prev[j]  if j ∉ O_i   # 前期以前の最終観測値
```

### 比較条件

| 条件 | 観測企業数 | 想定される挙動 |
|---|---|---|
| full_obs | 80 / 80 | 全員が同時反応 → 時差なし |
| partial_obs | 20 / 80 | ハブ近傍投資家が先行 → 時差あり |

## 実施内容のメモ

最初の実装（エッジが残った企業すべてを観測）では平均76.7/80社が観測対象になり差が出なかった。観測ユニバースを明示的に20社に制限してから再実行した。

## 結果

| 指標 | real\_tail | full\_obs | partial\_obs |
|---|---:|---:|---:|
| std | 0.01065 | 0.01266 | 0.01234 |
| skew | +0.158 | +0.040 | +0.007 |
| kurtosis | 10.10 | 6.17 | 6.14 |
| \|r\| ACF lag-1 | 0.163 | 0.059 | **0.067** |
| \|r\| ACF lag-5 | 0.198 | 0.008 | **0.019** |
| leverage | -0.043 | +0.012 | +0.014 |
| 株債相関 | -0.059 | -0.072 | -0.072 |

## 解釈

### 時差メカニズムの確認

**partial_obs では |r| ACF lag-1 と lag-5 が改善した。**

- lag-1: 0.059 → 0.067（+14%）
- lag-5: 0.008 → 0.019（+130%）

これは「ハブ企業でショックが起きたとき、$O_i \ni \text{hub}$ の投資家のみが即座に反応し、$O_i \not\ni \text{hub}$ の投資家は翌期以降に陳腐化情報から気づく」という時差メカニズムが働いていることを示す。情報伝播の遅れがリターンの時系列相関として現れた。

ただし、実データ（lag-1: 0.163、lag-5: 0.198）との差は依然大きく、改善の余地がある。

### まだ差が小さい理由

1. **観測ユニバースの設計が荒い**: 20社中10社が専門セクター、残り10社はグラフ重みが高い企業。より「エッジ特化型」（専門セクターのみ＋ハブ数社）にするとより強い時差が生まれうる
2. **陳腐化のスピードが速い**: $s$ の自己回帰 $\phi_s = 0.82$ は1ステップで急速に減衰する。前期値を使い続けることのペナルティが小さい
3. **価格インパクトが小さい**: `price_impact = 0.008` のため、先行者優位の取引量が最終価格に与える影響が小さい
4. **指数の時価総額加重平均**: 個別銘柄レベルの時差効果が指数計算でさらに希薄化する

## 結論

部分観測を導入することで「情報伝播の時差」が生まれ、|r| ACF（ボラティリティクラスタリングの指標）が改善することが確認できた。これは **variant_E〜H で一貫して効かなかったグラフ多様性が、部分観測という条件下では初めて機能した**ことを意味する。

実データ水準に近づけるには：
- セクター専門化の強化（非専門企業は完全に観測しない）
- 価格インパクトの増大
- 陳腐化情報の影響を強化（前期値でなく複数期前の値を使う）

など、さらなる調整が必要。
