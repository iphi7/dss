# I_variant_I_partial_obs

## 概要

アブレーション: **部分観測（投資ユニバース限定）**

各投資家が観測できる企業を $O_i$（専門セクター + グラフ上の重要上位企業、計約20社）に限定する。$O_i$ 外の企業は前期の観測値を使い続ける（陳腐化した情報）。

## 検証の動機

variant_E〜H で一貫して、グラフ $W_i$ の多様性がスタイライズドファクトに影響しなかった。根本原因は「全投資家が全企業の $y_j$ を同時に観測するため、ハブショック時の反応に時差が生まれない」こと（問題点.md 問題6）。部分観測を入れることでこの時差を生み出す。

## 実装

```python
obs_mask_i = 専門セクター企業 | グラフ重みスコア上位企業  # 計20社
y_i = np.where(obs_mask_i, y_full, y_known_prev[i])
```

## 結果

| 指標 | full_obs | partial_obs |
|---|---:|---:|
| \|r\| ACF lag-1 | 0.059 | **0.067** |
| \|r\| ACF lag-5 | 0.008 | **0.019** |

→ **部分観測で |r| 自己相関が改善。グラフ多様性が初めてスタイライズドファクトに影響した。**
