# W_goal05_variant_W_decile10_leverage 検証レポート

## 目的

高ボラ十分位10の leverage が実データより負に強い問題を抑える。
特に、5d付近で0.1弱ほど絶対値を小さくし、実データに近づける。

## Round1

V06周辺から、market-wide fear / asym_pi / down_ewma を弱めた。

結果:

- W03は decile10 5d をかなり弱めた。
- ただし `sq_acf5` がかなり落ちた。
- W02は中間的だが、まだ decile10 がやや強い。

## Round2

W02/W03の中間を探索した。

最も良かったのは `W04_mid_asym035 seed2`。

| 指標 | real | W04 |
|---|---:|---:|
| decile10 1d | -0.147 | -0.293 |
| decile10 3d | -0.203 | -0.262 |
| decile10 5d | -0.209 | -0.208 |
| decile10 7d | -0.180 | -0.162 |
| decile10 10d | -0.176 | -0.126 |
| decile10 20d | -0.160 | -0.073 |
| decile1 5d | -0.031 | -0.022 |
| sq_acf5 | 0.228 | 0.127 |

## 解釈

W04は、5d〜7dの分位10 leverageをかなり良くする。
一方、1d〜3dではまだ負に強く、10d〜20dでは弱くなりすぎる。
つまり、leverage curve の時間形状がまだ実データと違う。

実データでは decile10 leverage が 1dから20dまで比較的なだらかに負で持続する。
W04では、短期が強く、中長期で急速に消える。

これは、down-memory / fear / asym_pi を弱めることで高ボラ後の持続が短くなりすぎたためと考えられる。

## 結論

今回の目的である「分位10 5d leverageを0.1弱ほど弱める」ことには成功した。
ただし、複数日全体の曲線としては未完成。

次に進めるなら、W04をベースに、短期1d〜3dを弱めつつ10d〜20dを少し戻す必要がある。
単純に down_ewma を戻すと1d〜3dも悪化する可能性があるため、短期の即時fearではなく、弱い中期余韻を別機構として入れる方が良い。
