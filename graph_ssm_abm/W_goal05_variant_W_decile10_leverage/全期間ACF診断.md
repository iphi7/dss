# 全期間ACF診断

## 結論

懸念通り、`Q_base6_variant_Q_longrun_stable` の最終候補は全期間で見ると volatility clustering が強すぎます。
特に `abs_acf` と `sq_acf` が実データよりかなり大きく、rolling 1260日評価だけでは過小評価されていました。

## 問題点

### 1. 絶対リターンACFが強すぎる

実データ全期間では

- `abs_acf1 ≈ 0.261`
- `abs_acf5 ≈ 0.289`
- `abs_acf10 ≈ 0.243`

ですが、Q17/Q20ではおおむね

- `abs_acf1 ≈ 0.58〜0.79`
- `abs_acf5 ≈ 0.54〜0.76`
- `abs_acf10 ≈ 0.49〜0.73`

となっており、かなり過剰です。

### 2. 二乗リターンACFも強すぎる

実データ全期間の `sq_acf5` は約 `0.228` ですが、Q17/Q20では `0.56〜0.76` 程度あります。
これはボラティリティ状態が長く固定されすぎていることを示唆します。

### 3. raw return の lag1 ACF が正に出すぎる

実データでは `r_acf1 ≈ -0.015` とほぼゼロ、やや負です。
Q17/Q20では `0.15〜0.18` 程度あり、リターンそのものに短期トレンドが残りすぎています。
これは効率的市場的な性質から見るとまずいです。

### 4. 標準偏差が高い

実データ全期間の `std_sp500` は約 `0.0105` ですが、Q17/Q20では `0.021〜0.028` 程度あります。
日次ボラが約2倍以上です。

### 5. 歪度が足りない

実データ全期間は `skew ≈ -0.677` ですが、Q17/Q20はおおむねゼロ近辺です。
leverage effect は出ていますが、分布そのものの左歪みは十分ではありません。

## そこまで悪くない点

- 年率リターンは Q17/Q20 で約 4〜6% 程度で、爆発/崩壊はかなり改善しています。
- 尖度は seed によって 7〜14 程度で、短期tailとしては悪くありません。ただし実データ全期間の 21.8 よりは低い場合があります。
- leverage は Q17/Q20 で負に出ています。ただし Q20 seed1 は `-0.135` と強すぎます。

## 次の改善方針

全期間ACF過剰の原因は、下落後 fear / 非対称 impact / activity impact の状態変数が長く効きすぎて、ボラティリティ・レジームが固定化されることだと思われます。

次にやるなら以下です。

1. `down_ewma_decay` を下げる、または fear と price impact の decay を分離する。
2. `impact_activity_scale` と `impact_activity_clip` を下げる。
3. `participation_vol_power` を下げ、ボラが高いときの取引参加増幅を弱める。
4. raw return ACF を消すため、momentum 項 `+0.25 * momentum` を弱めるか削除する。
5. rolling window だけでなく、全期間 ACF を目的関数に入れる。
