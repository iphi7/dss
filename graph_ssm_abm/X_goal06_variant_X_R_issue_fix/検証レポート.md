# X_goal06_variant_X_R_issue_fix 検証レポート

## 目的

`R_base7_variant_R_acf_control` をベースに、以下の問題を同時に改善できるかを検証した。

- decile10 leverage の多日形状: 1d/3d が強すぎず、10d/20d が弱すぎないこと
- `|r|` / `r^2` の multi-lag ACF を大きく崩さないこと
- 尖度・tailを極端に悪化させないこと

評価では seed 1/2 の複数サンプルを使い、各 round で複数アイデアを同時に比較した。

- R12 の low fear / mid asym
- tail軽量化

## Round3

短期fearをさらに弱め、弱い非対称性を長く残すことで10d/20dを補えるかを試した。

結果として、`X13` はACFを戻したが、decile10の5d以降が弱くなった。`X16` は形状は悪くないがACFが弱い。

つまり、**弱い長期非対称性だけでは10d/20d leverageを十分には戻せなかった**。

## 暫定結論

Rベースで今回試した範囲では、完全解決には届いていない。

現時点の候補は次の通り。

1. **単一サンプルの総合バランス:** `X09_X03_less_short_leverage_seed2`
2. **平均スコアと形状の安定感:** `X04_R12_low_fear_mid_asym`
3. **ACFを戻す方向の参考:** `X13_X09_slow_weak_asym_seed2`

特に `X09 seed2` は、R03より短期decile10過剰が少し抑えられており、5dも実データに近い。ただし20dが弱い。

## 重要な知見

- tiny rebalancing は長期レジームを抑えるが、強くすると `|r|` / `r^2` ACF を消しすぎる。
- stop-loss / immediate fear は decile10 の1d/3dをすぐ強くしすぎる。
- activity復元はACFを戻すが、seed2で短期decile10を強めやすい。
- 弱い長期asymだけでは20d leverageを十分に戻せない。

## 次の方向

次にやるなら、単なるパラメータ調整ではなく、以下のような投資家側の機構追加が必要そう。

1. 高ボラ時にリスク選好的投資家だけが数日〜数週間参加率を上げる。
2. リスク回避型は短期で退避するが、リスク選好型は中期で流動性を供給/投機する。
3. これにより immediate fear ではなく、投資家ヘテロ性から中期ボラを作る。
